# 0단계 준비하기

> **실행 환경: 도커.** 명령은 컨테이너 안(bash)에서 칩니다. 교안의 PowerShell 명령은 [도커로 실행하기](../docker/00_도커로_실행하기.md)의 명령 대응표(4절)를 보고 바꿔 씁니다. 편집은 Windows 의 VS Code 에서 합니다.

| | |
|---|---|
| 시간 | 1시간 |
| 준비물 | Windows PC, 인터넷, OpenRouter 계정 |
| 결과 | Git 과 OpenCode 가 설치되고, AI 와 연결된다 |

0단계는 **프로그래밍 언어를 배우지 않습니다.** HTML 과 CSS 는 글로 된 설계도처럼 읽을 수 있는 정도만 익히고, 실제로는 AI 가 씁니다. 그래서 설치할 것은 Git 과 OpenCode 두 가지입니다. Python 은 필요 없습니다.

---

## 1. 설치할 두 가지

| 도구 | 하는 일 | 받는 곳 |
|---|---|---|
| Git for Windows | 변경 기록을 남긴다. Git Bash 도 제공한다 | https://git-scm.com/download/win |
| OpenCode | AI 에이전트. 파일을 읽고 고친다 | 아래 3번 |

Git 설치 때 선택지는 모두 기본값으로 둡니다.

## 2. Git 확인

PowerShell 을 새로 열고 칩니다.

**[PS]**

```powershell
git --version
```

`git version 2.x.x` 가 나오면 됩니다.

## 3. OpenCode 설치 (Git Bash 에서)

시작 메뉴에서 **Git Bash** 를 열고 칩니다.

**[Git Bash]**

```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

끝나면 Git Bash 를 **닫고 다시 엽니다.** 확인합니다.

**[Git Bash]**

```bash
opencode --version
```

버전 번호가 나오면 됩니다. 나오지 않으면 Git Bash 를 새로 열었는지 확인하고, 강사에게 알려 주세요.

## 4. OpenRouter 키 만들기

1. https://openrouter.ai 에 가입합니다.
2. **Credits** 에서 크레딧을 충전합니다. 최소 금액으로 시작하세요.
3. **Keys** 에서 **Create Key** 를 누르고 키를 복사합니다. (`sk-or-v1-` 로 시작)

> 키는 비밀번호와 같습니다. 채팅이나 화면 공유에 보여 주지 않습니다.

## 5. OpenCode 에 키 연결하기

1. Git Bash 에서 `opencode` 를 칩니다.
2. 입력 칸에 `/connect` 를 치고 **OpenRouter** 를 고른 뒤 키를 붙여 넣습니다.
3. `/models` 를 쳐서 목록이 나오면 연결된 것입니다.
4. `/exit` 로 나옵니다.

## 6. 작업 폴더 만들기

**[PS]**

```powershell
New-Item -ItemType Directory C:\harness-lab
git clone https://github.com/sinaboro/harness-beginner-tutorial C:\harness-beginner-tutorial
git config --global user.name "본인 이름"
git config --global user.email "본인 메일"
```

`C:\harness-beginner-tutorial\templates\stage0` 폴더가 보이면 준비가 끝났습니다.

---

## 확인 체크리스트
- [ ] `git --version` 이 나온다
- [ ] Git Bash 에서 `opencode --version` 이 나온다
- [ ] OpenCode 에서 `/models` 를 쳤을 때 목록이 나온다
- [ ] `C:\harness-lab` 폴더가 있다

## 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `opencode` 를 찾을 수 없다 | Git Bash 를 닫고 새로 연다. PowerShell 에서 치면 안 된다. |
| `/models` 목록이 비어 있다 | 키를 잘못 붙였거나 크레딧이 없다. OpenRouter 의 Keys, Credits 를 확인한다. |
| `git clone` 이 실패한다 | 인터넷 연결을 확인하고 다시 실행한다. |
