# 0단계 2장. 말로 된 요구사항 쓰기

> **실행 환경: 도커.** 명령 블록은 컨테이너 안(bash)에서 칩니다. `[Windows]` 로 표시된 블록만 Windows PowerShell 에서 칩니다. 파일 편집은 Windows 의 VS Code 에서 합니다. 자세한 설명은 [도커로 실행하기](../docker/00_도커로_실행하기.md)를 봅니다.

| | |
|---|---|
| 시간 | 1시간 30분 |
| 준비물 | 1장 완료 |
| 결과 | 명함 페이지의 요구사항을 "이렇게 하면 → 이런 결과" 형식으로 쓴다 |

## 학습 목표
1. 흐린 말과 확인할 수 있는 말을 구분한다.
2. 요구사항의 세 칸(이렇게 하면, 이런 결과, 잘못 쓰면)을 채운다.

---

## 1. 개념 — 요구사항은 AI 와의 약속

요구사항이 흐리면 AI 는 빈 곳을 제멋대로 채웁니다. 1장 실험 A 에서 내 이름 없이 페이지가 만들어진 것도 약속이 없었기 때문입니다.

| 흐린 말 | 확인할 수 있는 말 |
|---|---|
| 예쁘게 만든다 | 바탕은 연한 회색, 이름은 진한 남색이다 |
| 잘 보이게 한다 | 이름 글자가 가장 크고, 그 아래 소개가 보인다 |
| 모바일에서도 보기 좋게 | 창을 좁혀도 글이 가로로 잘리지 않고, 세로로 쌓인다 |
| 간단하게 | 파일은 두 개, 기능은 세 가지까지만 |

> 확인 방법을 적을 수 없는 말은 요구사항에 넣지 않습니다.

## 2. 따라 하기

### 1단계. 흐린 말 고치기 (15분)

아래 문장에서 흐린 낱말을 찾아 동그라미를 칩니다.

> 명함은 예쁘고, 보기 좋고, 누구나 쉽게 읽을 수 있어야 한다.

각각을 확인할 수 있는 말로 바꿉니다.

| 흐린 말 | 바꾼 말 |
|---|---|
| 예쁘고 | |
| 보기 좋고 | |
| 쉽게 읽을 수 있어야 | |

### 2단계. 명함 요구사항 쓰기 (30분)

저장소의 `templates/stage0/REQ_명함.md` 를 엽니다. 이미 쓰인 예시가 있으니 읽기만 합니다.

**[Windows]**

```bash
# (Windows) /tutorial/templates/stage0/REQ_명함.md 을(를) VS Code 로 열어 고칩니다
```

이번에는 **나만의 명함**을 씁니다. 같은 틀을 복사해서 채웁니다.

**[컨테이너]**

```bash
mkdir -p /workspace/명함요구사항
cp /tutorial/templates/stage0/REQ_명함.md /workspace/명함요구사항/내명함.md
# (Windows) /workspace/명함요구사항/내명함.md 을(를) VS Code 로 열어 고칩니다
```

조건은 다음과 같습니다.

- 기능은 **세 가지**만 씁니다. (이름과 소개, 취미 목록, 연락 링크)
- 각 기능에 "잘못 쓰면" 칸을 채웁니다.
- "만들지 않는 것"에 두 가지 이상 적습니다.

### 3단계. 점검하기 (15분)

- [ ] 옆 사람이 읽고 같은 페이지를 만들 수 있는가?
- [ ] 모든 기능에 "잘못 쓰면" 칸이 있는가?
- [ ] 결과를 눈으로 확인할 수 있는 말만 있는가?

### 4단계. 옆 사람과 바꿔 읽기 (15분)

옆 사람의 요구사항을 읽고, 질문을 한 개씩 적습니다. 질문이 많으면 약속이 약하다는 뜻입니다.

예: "연락 링크를 누르면 이메일 창이 열리나요, 아니면 웹 페이지가 열리나요?" → 답이 적혀 있지 않으면 고칩니다.

---

## 3. 확인하기
- [ ] 흐린 말을 세 개 이상 확인할 수 있는 말로 바꿨다.
- [ ] 명함 요구사항에 세 기능과 "잘못 쓰면" 칸을 모두 채웠다.
- [ ] 옆 사람에게서 질문을 하나 이상 받았다.

## 4. 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| "잘", "예쁘게"가 계속 나온다 | 1단계 표로 돌아간다. |
| "잘못 쓰면"을 무엇으로 쓸지 모르겠다 | 비울 때, 빈칸을 넣을 때, 너무 길 때를 하나씩 생각한다. |

## 5. 확인 문제
1. "예쁘게 만든다"를 확인할 수 있는 말로 바꾸시오.
2. "잘못 쓰면" 칸이 비어 있으면 AI 에게 무슨 일이 생기는가?
3. 요구사항에 "자바스크립트로 만든다"를 적으면 안 되는 이유는 무엇인가?
