# 0단계 4장. 규칙과 권한 세우기

> **실행 환경: 도커.** 명령은 컨테이너 안(bash)에서 칩니다. 교안의 PowerShell 명령은 [도커로 실행하기](../docker/00_도커로_실행하기.md)의 명령 대응표(4절)를 보고 바꿔 씁니다. 편집은 Windows 의 VS Code 에서 합니다.

| | |
|---|---|
| 시간 | 1시간 30분 |
| 준비물 | 3장 완료, `templates/stage0/AGENTS_빈칸.md`, `templates/stage0/opencode.jsonc` |
| 결과 | 규칙 문서를 채우고, 권한이 막는 일과 묻는 일을 직접 확인한다 |

## 학습 목표
1. **규칙(부탁)** 과 **권한(잠금장치)** 의 차이를 말한다.
2. `AGENTS.md` 에 꼭 들어갈 문장을 채운다.
3. 권한 설정을 읽고, 막히는 일을 직접 확인한다.

---

## 1. 개념

| | 규칙 (AGENTS.md) | 권한 (opencode.jsonc) |
|---|---|---|
| 성격 | 부탁 | 잠금장치 |
| 작동 | AI 가 읽고 따른다 | 금지된 일은 실행 자체가 막힌다 |
| 잊거나 어기면 | 어길 수 있다 | 막힌다 |

> 교실 문에 "들어가지 마시오"라고 써 붙이는 것이 규칙, 문을 잠그는 것이 권한입니다. 둘 다 있어야 합니다.

### 권한 한 줄 읽기

```jsonc
{ "action": "shell", "resource": "git commit *", "effect": "deny" }
```

| 칸 | 뜻 |
|---|---|
| action | 무엇을 하려는가 (shell: 명령, edit: 파일 고치기, read: 파일 읽기) |
| resource | 무엇에 대해서인가 (`*` 는 아무 글자나) |
| effect | allow(허용) / ask(물어봄) / deny(금지) |

규칙은 위에서 아래로 읽고, **가장 아래에 걸린 규칙이 이깁니다.**

### 2단계. AGENTS.md 채우기 (30분)

**[PS]**

```powershell
notepad AGENTS.md
```

`[작성]` 을 채웁니다.

| 절 | 무엇을 적나 | 예 |
|---|---|---|
| 1. 목표와 사용자 | 페이지의 목적과 보는 사람 | 자기소개 명함, 처음 만나는 사람 |
| 2. 파일 나누기 | 고쳐도 되는 파일 | index.html, style.css 만 고친다 |
| 3. 일하는 순서 | 계획, 승인, 만들기, 확인, 보고 | 계획을 말하고 "진행"을 기다린다 |
| 4. 하지 말 것 | 저장, 체크리스트, 외부 파일 | 저장은 하지 않는다. CHECKLIST.md 는 고치지 않는다. |
| 5. 쓰기 규칙 | 주석과 글꼴 | 두 파일 안의 모든 줄에 한국어 설명을 단다 |
| 6. 완료 확인 | 무엇을 확인하나 | CHECKLIST.md 를 모두 체크한다 |
| 7. 보고 형식 | 보고에 들어갈 것 | 한 일, 바뀐 파일, 확인한 항목 |

**꼭 들어가야 할 다섯 문장.** 빠진 것이 있으면 추가합니다.
- [ ] 계획을 먼저 말하고, 사람의 "진행"을 기다린다는 문장
- [ ] CHECKLIST.md 를 고치지 않는다는 문장
- [ ] 저장은 하지 않는다는 문장
- [ ] 완료라고 말하기 전 체크리스트를 확인한다는 문장
- [ ] 바뀐 파일과 확인한 항목을 보고한다는 문장

### 3단계. 권한 설정 읽기 (15분)

**[PS]**

```powershell
notepad opencode.jsonc
```

아래 질문에 답합니다.

1. AI 가 `CHECKLIST.md` 를 고치려 하면? (allow / ask / deny)
2. AI 가 `git commit` 을 실행하려 하면?
3. AI 가 `index.html` 을 고치려 하면? (힌트: 걸리는 `edit` 규칙이 있나?)
4. AI 가 인터넷에서 그림을 가져오려 하면?

> 정답: 1 deny, 2 deny, 3 걸리는 규칙이 없으니 허용, 4 deny

### 4단계. 막히는지 확인하기 (25분)

**[PS]**

```powershell
git init
opencode
```

OpenCode 에서 하나씩 시키고 결과를 적습니다.

**[AI]**

```text
CHECKLIST.md 의 첫 줄에 "확인함" 이라고 적어 줘.
```

**[AI]**

```text
git commit -m "test" 를 실행해 줘.
```

**[AI]**

```text
구글에서 명함 그림을 찾아서 내려받아 줘.
```

| 시킨 일 | 기대하는 결과 | 실제 결과 |
|---|---|---|
| CHECKLIST.md 고치기 | 막힌다 (deny) | |
| git commit 실행 | 막힌다 (deny) | |
| 인터넷에서 그림 찾기 | 막힌다 (deny) | |

확인이 끝나면 `/exit` 로 나온 뒤 `git status` 로 파일이 바뀌지 않았는지 봅니다.

**[PS]**

```powershell
git status
```

| AI 가 AGENTS.md 를 읽지 않는다 | 파일이 `C:\harness-lab\card4` 맨 위에 있는지 확인하고 OpenCode 를 새로 연다. |
