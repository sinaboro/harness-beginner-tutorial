# 0단계 3장. 작업 지시서 쓰기

| | |
|---|---|
| 시간 | 1시간 30분 |
| 준비물 | 2장의 요구사항 |
| 결과 | 지시서 여섯 칸을 채워 AI 에게 건네고, 계획을 검토해 승인한다 |

## 학습 목표
1. 지시서의 여섯 칸을 말한다.
2. 한 줄 지시와 지시서 지시의 결과를 비교한다.
3. AI 의 계획을 검토하고 고치게 한다.

---

## 1. 개념 — 일을 나눠 주는 쪽지

| 칸 | 질문 | 빠지면 생기는 일 |
|---|---|---|
| 1. 목표 | 끝나면 무엇이 되어 있나? | 어디까지가 끝인지 모른다 |
| 2. 요구사항 | 어느 번호를 만드나? | 모양을 AI 가 지어낸다 |
| 3. 범위 | 어떤 파일을 고쳐도 되나? | 관계없는 파일이 생긴다 |
| 4. 하지 말 것 | 무엇을 덧붙이면 안 되나? | 시키지 않은 것이 생긴다 |
| 5. 완료 조건 | 끝났는지 무엇으로 확인하나? | "다 했습니다"를 믿을 수밖에 없다 |
| 6. 진행 방법 | 계획을 먼저 말하나? | 방향이 틀려도 끝나고서야 안다 |

> 완료 조건은 **확인할 수 있는 말**로 씁니다. "잘 보인다"가 아니라 "CHECKLIST.md 의 2단계를 모두 체크한다"처럼 씁니다.

---

## 2. 따라 하기

### 1단계. 빈칸 틀 복사하기 (5분)

**[PS]**

```powershell
New-Item -ItemType Directory C:\harness-lab\지시서연습
Copy-Item C:\harness-beginner-tutorial\templates\TASK_빈칸.md C:\harness-lab\지시서연습\지시서.md
notepad C:\harness-lab\지시서연습\지시서.md
```

> `TASK_빈칸.md` 는 1단계의 틀입니다. 0단계에서는 같은 여섯 칸을 쓰되, 아래 예시를 참고해 HTML 과 CSS 에 맞게 고칩니다.

### 2단계. 여섯 칸 채우기 (30분)

2장에서 쓴 명함 요구사항을 바탕으로 채웁니다. 예시는 다음과 같습니다.

| 칸 | 예시 |
|---|---|
| 1. 목표 | 명함 페이지를 파일 두 개(index.html, style.css)로 만든다 |
| 2. 요구사항 | 명함 요구사항 R1~R5 |
| 3. 범위 | 고쳐도 되는 파일: index.html, style.css / 고치면 안 되는 파일: CHECKLIST.md, AGENTS.md |
| 4. 하지 말 것 | 자바스크립트, 그림 파일, 외부 글꼴, 요구사항에 없는 섹션 |
| 5. 완료 조건 | CHECKLIST.md 의 항목을 모두 체크했다 |
| 6. 진행 방법 | 계획을 먼저 말하고, "진행" 전에는 파일을 만들지 않는다 |

### 3단계. 한 줄 지시와 비교하기 (20분)

1장 실험 A 와 이번 지시를 비교할 수 있도록, 새 폴더에서 지시서를 건넵니다.

**[PS]**

```powershell
New-Item -ItemType Directory C:\harness-lab\card3
cd C:\harness-lab\card3
opencode
```

**[AI]**

```text
C:\harness-lab\지시서연습\지시서.md 를 읽고 그 지시대로 작업해 줘. 먼저 계획만 말하고 내 승인을 기다려.
```

> 파일을 읽지 못하면 지시서 내용을 그대로 붙여 넣습니다.

### 4단계. 계획 검토하기 (20분)

AI 의 계획을 아래 질문으로 검토합니다.

- [ ] 고칠 파일이 index.html 과 style.css 뿐인가?
- [ ] 자바스크립트, 그림, 외부 글꼴을 쓰겠다는 말이 없는가?
- [ ] CHECKLIST.md 를 고치겠다는 말이 없는가?
- [ ] 연락 링크와 취미 목록을 계획에 넣었는가?

맞지 않으면 짚어서 고치게 합니다.

**[AI]**

```text
계획 2번에 그림 파일이 들어 있어. 지시서 4번에서 "하지 말 것"에 적은 것이라 빼고 다시 말해 줘.
```

맞으면 승인합니다.

**[AI]**

```text
진행
```

### 5단계. 결과 확인하기 (15분)

AI 가 끝나면 지시서 5번을 직접 확인합니다.

**[PS]**

```powershell
cd C:\harness-lab\card3
dir
```

- [ ] 파일이 index.html 과 style.css 두 개뿐이다.
- [ ] 두 파일을 더블클릭하면 브라우저에 페이지가 보인다.

### 6단계. 비교표 채우기 (10분)

| 항목 | 1장 실험 A (한 줄) | 3장 (지시서) |
|---|---|---|
| 계획을 먼저 말했나? | | |
| 시키지 않은 것이 있나? | | |
| 완료를 확인할 방법이 있었나? | | |

## 3. 확인하기
- [ ] 지시서 여섯 칸을 모두 채웠다.
- [ ] 계획에서 빠지거나 넘친 것을 하나 이상 고치게 했다.
- [ ] 두 파일이 브라우저에서 열린다는 것을 내 눈으로 확인했다.

## 4. 좋은 지시와 나쁜 지시

| 나쁜 지시 | 좋은 지시 |
|---|---|
| "명함 만들어 줘" | "지시서대로 index.html 과 style.css 를 만든다. 자바스크립트는 쓰지 않는다." |
| "디자인 이상해요, 고쳐 줘" | "바탕이 너무 밝다. 요구사항 R5 의 색으로 바꿔 줘. 다른 것은 바꾸지 마." |
| "알아서 잘 해 줘" | "두 방법이 있으면 장단점을 말하고 내가 고르게 해 줘." |

## 5. 확인 문제
1. 지시서의 여섯 칸을 순서대로 말하시오.
2. 완료 조건을 "예쁘게 보이면 됨"으로 쓰면 어떤 문제가 생기는가?
3. "범위"와 "하지 말 것"의 차이를 설명하시오.
