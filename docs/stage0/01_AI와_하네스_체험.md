# 0단계 1장. AI 와 하네스 체험

> **실행 환경: 도커.** 명령은 컨테이너 안(bash)에서 칩니다. 교안의 PowerShell 명령은 [도커로 실행하기](../docker/00_도커로_실행하기.md)의 명령 대응표(4절)를 보고 바꿔 씁니다. 편집은 Windows 의 VS Code 에서 합니다.

| | |
|---|---|
| 시간 | 1시간 30분 |
| 준비물 | 00 준비하기 완료 |
| 결과 | 같은 부탁을 조건 없이 한 것과 조건을 붙인 것을 비교한다 |

## 학습 목표
1. AI 모델과 AI 에이전트의 차이를 말한다.
2. "하네스"가 무엇인지 말로 설명한다.
3. 조건을 붙이면 결과가 달라지는 것을 내 눈으로 확인한다.

---

## 1. 개념

| 낱말 | 한 문장 설명 | 비유 |
|---|---|---|
| AI 모델 | 글을 받아 글로 답한다. 내 파일은 보지 못한다. | 전화로 대답하는 상담원 |
| AI 에이전트 | 모델의 말대로 파일을 만들고 고친다. (이 교안에서는 OpenCode) | 상담원의 지시로 일하는 직원 |
| 하네스 | 에이전트의 일을 통제하는 장치 전체 | 말에게 씌우는 마구 |

> **하네스(harness)** 는 말에게 씌우는 마구입니다. 말은 힘이 세지만 마구가 없으면 원하는 방향으로 달리지 못합니다. 마구는 힘을 줄이는 것이 아니라 쓸모 있게 만드는 것입니다.

하네스는 다섯 가지로 이루어집니다.

| 요소 | 질문 | 이 단계에서 만나는 것 |
|---|---|---|
| 규칙 | 어떻게 일해야 하나? | AGENTS.md (4장) |
| 도구 | 무엇으로 일하나? | OpenCode, 브라우저 |
| 권한 | 어디까지 해도 되나? | opencode.jsonc (4장) |
| 실행 | 어디에서 일하나? | 작업 폴더 `C:\harness-lab` |
| 확인 | 다 됐는지 어떻게 아나? | CHECKLIST.md (5장) |

## 2. 따라 하기

### 1단계. 실험 A — 아무 조건 없이 시키기 (20분)

**[PS]**

```powershell
New-Item -ItemType Directory C:\harness-lab\card-a
cd C:\harness-lab\card-a
opencode
```

OpenCode 입력 칸에 한 줄만 씁니다.

**[AI]**

```text
내 자기소개 페이지를 HTML 로 만들어 줘.
```

AI 가 끝낼 때까지 기다린 뒤 `/exit` 로 나옵니다. 아래 표를 채웁니다.

| 관찰할 것 | 내 기록 |
|---|---|
| 계획을 먼저 말했나? | |
| 파일을 몇 개 만들었나? 이름은? | |
| 내 이름이나 취미를 물어봤나? 제멋대로 채웠나? | |
| 그림, 외부 글꼴, 자바스크립트를 넣었나? | |
| 완성이라고 했는데, 무엇으로 확인했나? | |

**[PS]**

```powershell
dir
```

파일을 더블클릭해서 브라우저로 열어 봅니다.

### 2단계. 실험 B — 조건을 붙여서 시키기 (25분)

**[PS]**

```powershell
New-Item -ItemType Directory C:\harness-lab\card-b
cd C:\harness-lab\card-b
opencode
```

**[AI]**

```text
자기소개 페이지를 HTML 과 CSS 로 만들어 줘.
조건 1. 파일은 index.html 과 style.css 두 개만 만든다.
조건 2. 그림, 외부 글꼴, 자바스크립트는 쓰지 않는다.
조건 3. 내 이름과 취미를 묻고, 답을 받은 뒤에 만든다. 먼저 질문만 해 줘.
```

AI 가 질문하면 이름과 한 줄 소개, 취미 세 개를 답합니다. 끝난 뒤 실험 A 와 같은 표를 채우고, 아래 두 칸을 더 채웁니다.

| 항목 | 실험 A | 실험 B |
|---|---|---|
| 파일 개수 | | |
| 자바스크립트나 외부 파일 | | |
| 내 정보를 물었나? | | |

### 3단계. 차이를 말로 설명하기 (15분)

실험 B 의 조건 세 개가 각각 무엇을 막으려고 한 것인지 적습니다.

| 조건 | 막으려는 것 |
|---|---|
| 조건 1 (파일 두 개) | |
| 조건 2 (외부 파일과 스크립트 금지) | |
| 조건 3 (먼저 묻기) | |

조건으로 적은 문장이 바로 **규칙(부탁)** 입니다. 4장에서 이런 문장을 `AGENTS.md` 에 옮깁니다.

## 3. 확인하기
- [ ] 실험 A 와 B 의 차이를 두 가지 이상 적었다.
- [ ] 조건 세 개가 각각 무엇을 막는지 말할 수 있다.
- [ ] 하네스의 다섯 요소를 말할 수 있다.

## 4. 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| AI 가 "모델을 선택하세요"라고 한다 | `/connect` 로 OpenRouter 키를 연결한다. (00 준비하기 5번) |
| 브라우저에서 파일이 열리지 않는다 | 파일 이름이 `index.html` 인지 확인한다. 확장자가 `.txt` 로 바뀌었으면 고친다. |
| AI 가 계획 없이 바로 만든다 | 정상이다. 이 단계에서는 규칙이 없다. 조건 3 을 붙여 다시 시킨다. |

## 5. 확인 문제
1. AI 모델과 AI 에이전트의 차이를 "파일"이라는 낱말로 설명하시오.
2. 실험 A 에서 AI 가 내 정보 없이 채운 것이 있다면, 그것이 왜 문제인가?
3. 하네스의 다섯 요소를 말하시오.
