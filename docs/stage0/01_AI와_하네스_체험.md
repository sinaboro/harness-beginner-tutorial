# 0단계 1장. AI 와 하네스 체험

> **실행 환경: 도커.** 명령 블록은 컨테이너 안(bash)에서 칩니다. `[Windows]` 로 표시된 블록만 Windows PowerShell 에서 칩니다. 파일 편집은 Windows 의 VS Code 에서 합니다. 자세한 설명은 [도커로 실행하기](../docker/00_도커로_실행하기.md)를 봅니다.

| | |
|---|---|
| 시간 | 1시간 30분 |
| 준비물 | 00 준비하기를 마친 상태 (컨테이너 안에서 `opencode` 가 `/models` 목록을 보여 준다) |
| 결과 | 조건 없이 시킨 결과와 조건을 붙여 시킨 결과를 표로 비교하고, 차이를 한 문장으로 말한다 |

## 이 장에서 할 일 한눈에 보기

1. 실험 A 폴더를 만들고, AI 에게 한 줄로 시킨다. (20분)
2. 실험 A 가 만든 파일을 확인하고 표 A 를 채운다. (15분)

4. 표 A 와 표 B 를 같은 항목끼리 비교해 차이를 적는다. (20분)
5. 조건 세 개가 막으려는 것을 적는다. (10분)

## 1단계. 실험 A — 조건 없이 한 줄로 시키기 (20분)

**무엇을:** 실험용 폴더를 만들고, OpenCode 에 문장 한 줄을 입력한다.

**[컨테이너]**

```bash
mkdir -p /workspace/card-a
cd /workspace/card-a
opencode
```

OpenCode 입력 칸에 아래 문장을 **그대로** 붙여 넣고 Enter 를 누릅니다. 다른 말은 덧붙이지 않습니다.

**[AI]**

```text
내 자기소개 페이지를 HTML 로 만들어 줘.
```

AI 가 작업을 끝낼 때까지 기다립니다. 끝나면 입력 칸에 `/exit` 를 치고 Enter 를 누릅니다.

## 2단계. 실험 A 결과 확인하고 표 채우기 (15분)

**무엇을:** AI 가 만든 파일을 확인하고, 아래 표의 빈칸에 **보이는 그대로** 적는다.

**[컨테이너]**

```bash
ls -la /workspace/card-a
```

확인 방법:
- 파일 목록에 있는 파일 이름을 표의 2번 칸에 적는다.
- 파일을 VS Code 에서 열어 `<img`, `<script`, `http` 가 들어 있는지 찾는다. 있으면 "있음", 없으면 "없음"을 적는다.
- 브라우저 확인은 Windows 에서 한다. `C:\harness-lab\card-a\index.html` 을 더블클릭해서 열고, 페이지에 **내 이름**이 있는지 본다.

| 항목 | 내가 확인해서 적은 내용 |
|---|---|
| 1. 작업 전에 계획을 말했는가? (대화 기록에 계획이 있는가) | |
| 2. 만든 파일 이름은? (ls 결과) | |
| 3. 내 이름이 들어 있는가? (있음 / 없음 / 가짜 이름이 들어 있음) | |
| 4. 그림, 외부 파일, 스크립트(`<img`, `<script`, `http`)가 있는가? | |
| 5. 완성했다고 말할 때, 무엇을 보고 확인했는가? (AI 의 말 한 줄을 그대로 적는다) | |

## 3단계. 실험 B — 조건 세 개를 붙여서 시키기 (25분)

**무엇을:** 실험 B 폴더를 만들고, 아래 문장을 **그대로** 입력한다.

**[컨테이너]**

```bash
mkdir -p /workspace/card-b
cd /workspace/card-b
opencode
```

**[AI]**

```text
자기소개 페이지를 HTML 과 CSS 로 만들어 줘.
조건 1. 파일은 index.html 과 style.css 두 개만 만든다.
조건 2. 그림, 외부 글꼴, 자바스크립트는 쓰지 않는다.
조건 3. 먼저 내 이름과 취미를 물어보고, 답을 받은 뒤에 만든다. 지금은 질문만 해 줘.
```

AI 가 질문하면 아래 답을 **그대로** 입력합니다.

**[AI]**

```text
이름은 홍길동, 소개는 "배우는 것을 좋아하는 사람", 취미는 독서, 산책, 요리입니다. 이제 만들어 줘.
```

(이름과 소개, 취미는 본인의 것으로 바꿔도 됩니다.) AI 가 끝나면 `/exit` 를 칩니다.

## 4단계. 표 B 채우고 표 A 와 비교하기 (20분)

**무엇을:** 실험 B 결과를 확인하고, 표 A 와 같은 항목을 나란히 적는다.

**[컨테이너]**

```bash
ls -la /workspace/card-b
```

확인 방법은 2단계와 같습니다. 파일 이름, 내 이름 확인, 외부 파일 확인을 합니다.

| 항목 | 실험 A (표 A 의 답) | 실험 B (이번 답) | 같은가, 다른가 |
|---|---|---|---|
| 1. 계획을 먼저 말했는가? | | | |
| 2. 파일 개수와 이름 | | | |
| 3. 내 이름이 들어 있는가? | | | |
| 4. 그림·외부 파일·스크립트가 있는가? | | | |

비교 방법:
- 같은 항목의 두 칸을 읽고, 다르면 "다름"이라고 적는다.
- 차이가 가장 큰 항목 **한 개**에 동그라미를 친다.

## 5단계. 조건 세 개가 막으려는 것 적기 (10분)

**무엇을:** 실험 B 에서 붙인 조건 세 개가 **각각 무엇을 막으려고 한 것인지** 적는다.

| 조건 | 막으려는 것 (한 문장) |
|---|---|
| 조건 1 (파일 두 개만) | |
| 조건 2 (그림, 외부 글꼴, 스크립트 금지) | |
| 조건 3 (먼저 묻기) | |

확인 기준: 각 칸의 문장에 "AI 가 ~하지 못하게" 또는 "~가 생기지 않게"라는 뜻이 들어 있어야 합니다. 들어 있지 않으면 다시 씁니다.

## 확인 체크리스트
- [ ] 표 A 의 다섯 항목을 모두 채웠다.
- [ ] 표 B 의 네 항목을 모두 채웠다.
- [ ] 같은 항목끼리 "같다/다르다"를 적었다.
- [ ] 조건 세 개가 막으려는 것을 각각 한 문장으로 적었다.
- [ ] 차이가 가장 큰 항목 한 개에 동그라미를 쳤다.

## 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `opencode` 가 "모델을 선택하세요"라고 한다 | 00 준비하기 5번의 `/connect` 를 다시 한다. |
| AI 가 질문하지 않고 바로 파일을 만든다 (실험 B) | 조건 3 을 한 글자도 바꾸지 않고 다시 입력한다. 그래도 그렇다면 `/new` 를 치고 처음부터 다시 입력한다. |
| 브라우저에서 페이지가 안 열린다 | 파일 이름이 `index.html` 인지 확인한다. 확장자가 `.txt` 로 바뀌었으면 VS Code 에서 파일 이름을 고친다. |
