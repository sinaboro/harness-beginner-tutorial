# 2단계 준비하기 (도커)

| | |
|---|---|
| 시간 | 30분 |
| 준비물 | 1단계를 마친 상태 (도커 이미지와 OpenRouter 연결이 있다) |
| 결과 | 컨테이너 안에 도서 대출 목록 작업 폴더가 만들어지고, 1단계 도구가 그대로 동작한다 |

2단계는 1단계와 **같은 도커 이미지**를 씁니다. 새로 설치할 것은 없습니다.

> **역할 나누기**
> - **Windows 쪽(PowerShell)**: 컨테이너를 켠다. `[Windows]` 표시.
> - **컨테이너 쪽(bash)**: 작업 폴더를 만들고 실습한다. `[컨테이너]` 표시.

---

## 1. 컨테이너 켜기 (Windows)

**[Windows]** (PowerShell)

```powershell
cd C:\harness-beginner-tutorial\docker
docker compose run --rm workspace
```

## 2. 도구 확인 (컨테이너 안)

**[컨테이너]**

```bash
python --version
python -m pytest --version
git --version
opencode --version
```

네 줄 모두 버전이 나와야 합니다. OpenCode 연결은 `opencode` → `/models` 로 확인하고 `/exit` 로 나옵니다.

## 3. 작업 폴더 만들기 (컨테이너 안)

**[컨테이너]**

```bash
mkdir -p /workspace/library/tests
cd /workspace/library
git init
git config core.hooksPath .githooks
```

> 이 폴더 `/workspace/library` 는 Windows 의 `C:\harness-lab\library` 입니다. 2장부터 7장까지 모두 여기서 합니다.

## 4. 1단계 도구 복사하기 (컨테이너 안)

**[컨테이너]**

```bash
T="/tutorial/templates"
cp "$T/verify.py" .
cp "/tutorial/templates/stage2/pytest.ini" .
cp "$T/opencode.jsonc" .
cp "$T/AGENTS_빈칸.md" AGENTS.md
cp "$T/.gitattributes" .
mkdir -p .githooks
cp "$T/pre-commit" .githooks/pre-commit
echo ".env" > .gitignore
ls -la
```

- `AGENTS.md` 는 1단계 4장에서 채운 것이 있다면 그것을 옮겨 씁니다. 없다면 빈칸 틀을 4장과 같은 방식으로 채웁니다.

- [ ] `git status` 가 실행된다
