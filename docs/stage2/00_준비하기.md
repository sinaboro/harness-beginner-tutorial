# 2단계 준비하기

| | |
|---|---|
| 시간 | 30분 |
| 준비물 | 1단계를 마친 상태 (Python, pytest, Git, OpenCode 가 동작한다) |
| 결과 | 2단계 작업 폴더가 만들어지고, 1단계 도구가 그대로 되는지 확인한다 |

2단계는 1단계와 같은 도구를 씁니다. 새로 설치할 것은 없습니다.

---

## 1. 도구 확인

**[PS]**

```powershell
python --version
python -m pytest --version
git --version
opencode --version
```

네 줄 모두 버전이 나오면 됩니다. 하나라도 안 나오면 1단계의 0장을 다시 봅니다.

## 2. OpenCode 연결 확인

Git Bash 에서 `opencode` 를 열고 `/models` 를 칩니다. 목록이 나오면 `/exit` 로 나옵니다.

## 3. 작업 폴더 만들기

**[PS]**

```powershell
New-Item -ItemType Directory C:\harness-lab\library
New-Item -ItemType Directory C:\harness-lab\library\tests
cd C:\harness-lab\library
git init
git config core.hooksPath .githooks
```

> 이 폴더 `C:\harness-lab\library` 에서 2장부터 7장까지 모두 합니다.

## 4. 1단계 도구 복사하기

**[PS]**

```powershell
$T = "C:\harness-beginner-tutorial\templates"
Copy-Item "$T\verify.py" .
Copy-Item "$T\stage2\pytest.ini" .
Copy-Item "$T\opencode.jsonc" .
Copy-Item "$T\AGENTS_빈칸.md" AGENTS.md
Copy-Item "$T\.gitattributes" .
New-Item -ItemType Directory .githooks
Copy-Item "$T\pre-commit" .githooks\pre-commit
Set-Content .gitignore ".env"
dir
```

- `AGENTS.md` 는 1단계 4장에서 채운 것이 있다면 그것을 옮겨 씁니다. 없다면 빈칸 틀을 4장과 같은 방식으로 채웁니다.
