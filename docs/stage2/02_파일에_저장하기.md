# 2단계 2장. 책 목록을 파일에 저장하기

> **실행 환경: 도커.** 명령 블록은 컨테이너 안(bash)에서 칩니다. `[Windows]` 로 표시된 블록만 Windows PowerShell 에서 칩니다. 파일 편집은 Windows 의 VS Code 에서 합니다. 자세한 설명은 [도커로 실행하기](../docker/00_도커로_실행하기.md)를 봅니다.

| | |
|---|---|
| 시간 | 2시간 |
| 준비물 | 1장의 `요구사항.md`, 준비하기를 마친 `/workspace/library` |
| 결과 | 책 등록, 목록, 파일 저장을 AI 에게 맡기고, 테스트와 대조한 뒤 저장한다 |

## 이 장에서 할 일 한눈에 보기

1. 테스트 기준 파일을 가져오고 읽는다. (15분)
2. 빨강을 확인한다. (10분)
3. AI 에게 지시서를 건네고 계획을 검토한다. (25분)
4. 초록을 확인하고 테스트 파일이 바뀌지 않았는지 대조한다. (15분)
5. 저장된 파일을 눈으로 확인한다. (15분)
6. 저장하기. (10분)

## 1단계. 테스트 기준 파일 가져와 읽기 (15분)

**[컨테이너]**

```bash
cd /workspace/library
cp /tutorial/templates/stage2/tests/test_books.py tests/
cp /tutorial/templates/stage2/TASK_책저장.md .
ls tests
```

**[Windows]** VS Code 에서 `C:\harness-lab\library\tests\test_books.py` 를 엽니다. 아래 세 질문에 **찾은 `assert` 줄**을 옮겨 적습니다.

| 질문 | 답 (찾은 줄을 그대로 옮긴다) |
|---|---|
| 1. `add_book` 이 돌려주는 책의 모양은? (`test_add_book_creates_available_book` 의 `assert book ==` 줄) | |
| 2. 공백뿐인 제목은 어떻게 되어야 하나? (`test_add_book_rejects_blank_title` 의 `with pytest.raises` 줄) | |
| 3. 파일이 없으면 `load_books` 는 무엇을 돌려주나? (`test_load_missing_file_returns_empty_list` 의 `assert` 줄) | |

## 2단계. 빨강 확인하기 (10분)

**[컨테이너]**

```text
(옮겨 적을 줄)
```

## 3단계. AI 에게 지시서 건네고 계획 검토하기 (25분)

**[컨테이너]**

```bash
cd /workspace/library
opencode
```

**[AI]**

```text
TASK_책저장.md 를 읽고 그 지시대로 작업해 줘. 먼저 계획만 말하고 내 승인을 기다려.
```

계획을 아래 네 질문으로 검토합니다.

| 질문 | 답 (예/아니오) | 아니오면 입력할 문장 |
|---|---|---|
| 1. 고치는 파일이 library.py 한 개뿐인가? | | 아래 문장 A |
| 2. 계획에 lend_book, return_book 이 없는가? (이번 장에서는 만들지 않는다) | | 아래 문장 A |
| 3. 계획에 tests/ 를 고친다는 말이 없는가? | | 아래 문장 A |
| 4. 계획에 데이터베이스, 웹 화면, 외부 패키지가 없는가? | | 아래 문장 A |

**[AI] 문장 A** (아니오일 때, 번호만 바꿔 입력합니다)

```text
계획 [번호]번이 TASK_책저장.md 와 맞지 않아. 그 부분을 빼고 계획을 다시 말해 줘. 아직 파일은 고치지 마.
```

모두 예이면 입력합니다.

**[AI]**

```text
진행
```

끝나면 `/exit` 를 칩니다.

## 4단계. 초록 확인하고 테스트 파일 대조하기 (15분)

**[컨테이너]**

```bash
cd /workspace/library
python -m pytest tests/test_books.py
diff tests/test_books.py /tutorial/templates/stage2/tests/test_books.py && echo "테스트 파일은 원본과 같습니다"
```

확인 기준:

| 확인할 것 | 기대하는 결과 | 실제 결과 (예/아니오) |
|---|---|---|
| 테스트 결과 | `6 passed` 가 나온다 | |
| 테스트 파일 | "테스트 파일은 원본과 같습니다"가 나온다 | |

아니오가 있으면 AI 에게 실패 줄을 알리고 `library.py` 만 고치게 합니다. 테스트 파일이 바뀌었다면 `cp /tutorial/templates/stage2/tests/test_books.py tests/` 로 원본을 다시 복사합니다.

## 5단계. 저장된 파일 눈으로 확인하기 (15분)

**[컨테이너]**

```bash
cd /workspace/library
python -c "
from library import add_book, save_books, load_books
books = []
add_book(books, '데미안', '헤세')
add_book(books, '노인과 바다', '헤밍웨이')
save_books(books, 'books.json')
print('저장 완료:', len(load_books('books.json')), '권')
"
cat books.json
```

확인 기준:
- `저장 완료: 2 권` 이 나와야 합니다.
- `cat books.json` 에 `"title": "데미안"` 처럼 한글이 **깨지지 않고** 보여야 합니다. `\uXXXX` 처럼 보이면 `ensure_ascii=False` 가 빠진 것입니다.

**[Windows]** VS Code 에서 `C:\harness-lab\library\books.json` 을 열어 같은 내용인지 봅니다.

## 6단계. 저장하기 (10분)

책 데이터 파일은 개인 기록이므로 저장소에 올리지 않습니다.

**[컨테이너]**

```bash
cd /workspace/library
echo "books.json" >> .gitignore
cat .gitignore
python verify.py
git add -A
git status
git commit -m "2장: 책 등록, 목록, JSON 저장 (R1, R2, R5)"
git log --oneline
```

확인 기준:
- `.gitignore` 에 `books.json` 줄이 있어야 합니다.
- `git status` 에 `books.json` 이 없어야 합니다.
- `git log --oneline` 에 커밋이 한 줄 생겨야 합니다.

## 확인 체크리스트
- [ ] 테스트 기준 세 질문에 찾은 줄을 옮겨 적었다.
- [ ] 빨강(ModuleNotFoundError 또는 ImportError)을 옮겨 적었다.
- [ ] 계획 검토 네 질문에 답했다.
- [ ] `6 passed` 와 테스트 파일 대조를 확인했다.
- [ ] `books.json` 의 한글이 깨지지 않았다.
- [ ] 커밋이 한 줄 생겼다.

## 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `ModuleNotFoundError: No module named 'library'` (4단계 이후) | AI 가 `library.py` 를 만들지 않았다. `ls` 로 확인하고 AI 에게 다시 말한다. |
| `JSONDecodeError` | `books.json` 을 손으로 고쳐서 형식이 깨졌다. 파일을 지우고 5단계를 다시 한다. |
| 한글이 `\uXXXX` 로 보인다 | AI 에게 "save_books 에 ensure_ascii=False 를 넣어 줘"라고 말한다. |
| `git status` 에 `books.json` 이 보인다 | 6단계의 `.gitignore` 줄이 빠졌다. 다시 `echo "books.json" >> .gitignore` 를 친다. |
