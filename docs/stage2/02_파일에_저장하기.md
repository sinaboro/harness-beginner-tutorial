# 2단계 2장. 책 목록을 파일에 저장하기

> **실행 환경: 도커.** 명령은 컨테이너 안(bash)에서 칩니다. 교안의 PowerShell 명령은 [도커로 실행하기](../docker/00_도커로_실행하기.md)의 명령 대응표(4절)를 보고 바꿔 씁니다. 편집은 Windows 의 VS Code 에서 합니다.

| | |
|---|---|
| 시간 | 2시간 |
| 준비물 | 1장 요구사항, 준비하기 완료 |
| 결과 | 책 등록과 목록, JSON 파일 저장을 AI 가 만들고, 테스트로 확인해 저장한다 |

## 학습 목표
1. 프로그램이 꺼지면 사라지는 것과 파일에 남는 것의 차이를 설명한다.
2. JSON 이라는 파일 형식을 읽을 수 있다.
3. 기준(테스트)을 먼저 보고, 빨강에서 초록으로 가는 흐름을 따른다.

---

## 1. 개념 — 상태를 파일에 남긴다

1단계 할 일 목록은 메모리에만 있었습니다. 프로그램을 끄면 사라졌습니다. 도서관은 **책 목록이 꺼져도 남아야** 합니다.

**JSON** 은 데이터를 글로 적는 형식입니다. 파이썬의 딕셔너리와 거의 같은 모양입니다.

```json
[
  {"id": 1, "title": "데미안", "author": "헤세", "status": "available", "borrower": null}
]
```

| JSON | 파이썬 |
|---|---|
| `{ }` | 딕셔너리 `{}` |
| `[ ]` | 리스트 `[]` |
| `null` | `None` |
| `true` / `false` | `True` / `False` |

## 2. 따라 하기

### 1단계. 기준(테스트) 읽기 (15분)

**[PS]**

```powershell
cd C:\harness-lab\library
Copy-Item C:\harness-beginner-tutorial\templates\stage2\tests\test_books.py tests\
notepad tests\test_books.py
```

아래 세 질문에 답합니다.

1. `add_book` 이 돌려주는 책은 어떤 모양인가? (딕셔너리의 키 다섯 개)
2. 공백뿐인 제목은 어떻게 되어야 하나?
3. 저장 파일이 아직 없으면 `load_books` 는 무엇을 돌려주나?

> 이 세 답이 AI 가 지켜야 할 약속입니다.

### 2단계. 빨강 확인하기 (10분)

**[PS]**

```powershell
python -m pytest tests\test_books.py
```

`library.py` 가 없으므로 실패합니다. 이것이 빨강입니다. 오류 줄에서 `No module named 'library'` 또는 비슷한 문장을 찾아 적습니다.

### 3단계. AI 에게 만들게 하기 (40분)

**[PS]**

```powershell
Copy-Item C:\harness-beginner-tutorial\templates\stage2\TASK_책저장.md .
opencode
```

**[AI]**

```text
TASK_책저장.md 를 읽고 그 지시대로 작업해 줘. 먼저 계획만 말하고 내 승인을 기다려.
```

계획을 검토합니다.

- [ ] 고칠 파일이 `library.py` 하나뿐인가?
- [ ] `lend_book`, `return_book` 을 만들겠다는 말이 없는가?
- [ ] `tests/` 를 고치겠다는 말이 없는가?

맞으면 `진행` 이라고 답합니다. 끝나면 `/exit` 로 나옵니다.

### 4단계. 빨강에서 초록으로 (15분)

**[PS]**

```powershell
python -m pytest tests\test_books.py
```

모두 통과해야 합니다. 실패가 있다면 실패한 테스트 이름과 `assert` 줄을 AI 에게 붙여 주고, 원인부터 설명하게 합니다. 테스트를 고쳐서 통과시키라고 하면 안 됩니다.

**[PS]**

```powershell
Compare-Object (Get-Content tests\test_books.py) (Get-Content C:\harness-beginner-tutorial\templates\stage2\tests\test_books.py)
```

아무것도 나오지 않으면 테스트는 바뀌지 않은 것입니다.

### 5단계. 저장 파일 눈으로 보기 (10분)

파이썬으로 책을 두 권 넣고 저장해 봅니다.

**[PS]**

```powershell
python -c "from library import add_book, save_books; b=[]; add_book(b,'데미안','헤세'); add_book(b,'노인과 바다','헤밍웨이'); save_books(b,'books.json'); print('저장 완료')"
notepad books.json
```

`books.json` 을 열어 보고, 1장의 요구사항 R5 와 대조합니다. 한글이 깨지지 않았는지 확인합니다.

> 프로그램을 끄고 다시 켜도 `books.json` 은 남습니다. 이것이 저장입니다.

### 6단계. 검증하고 저장하기 (10분)

먼저 책 데이터 파일을 저장소에서 제외합니다. 책 데이터는 개인 기록이므로 올리지 않습니다.

**[PS]**

```powershell
Add-Content .gitignore "books.json"
python verify.py
git add -A
git status
git commit -m "2장: 책 등록, 목록, JSON 저장 (R1, R2, R5)"
```

`git status` 에 `books.json` 이 없어야 합니다. `.gitignore` 에 있으므로 보이지 않는 것이 정상입니다.

## 3. 확인하기
- [ ] 빨강(실패)을 보고 원인을 말할 수 있다.
- [ ] `python verify.py` 가 "검증 통과"로 끝났다.
- [ ] `books.json` 을 열어 보고 한글이 깨지지 않았음을 확인했다.
- [ ] 저장 커밋이 한 줄 생겼다.

## 4. 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `ModuleNotFoundError: No module named 'library'` | `library.py` 가 없거나 폴더가 다르다. `dir` 로 확인한다. |
| `books.json` 의 한글이 `\uXXXX` 로 보인다 | `ensure_ascii=False` 를 빠뜨렸다. AI 에게 `save_books` 를 고치게 한다. |
| 저장한 파일을 읽을 때 `JSONDecodeError` | 파일을 메모장에서 직접 고쳐서 형식이 깨졌다. 파일을 지우고 다시 저장한다. |

## 5. 확인 문제
1. 메모리에만 있던 데이터와 파일에 저장한 데이터의 차이를 한 문장으로 쓰시오.
2. JSON 의 `null` 은 파이썬의 무엇에 해당하나?
3. `books.json` 을 저장소에 올리지 않는 이유는 무엇인가?
