# 2단계 1장. 도서관 요구사항 쓰기

| | |
|---|---|
| 시간 | 2시간 |
| 준비물 | 준비하기 완료 |
| 결과 | 도서 대출 목록의 요구사항을 "이렇게 하면 → 이런 결과 → 잘못 쓰면"으로 쓴다 |

## 학습 목표
1. 생활 속 규칙("이미 빌려 간 책은 못 빌린다")을 요구사항으로 옮긴다.
2. 상태(대출 가능, 대출 중)를 명확한 말로 정한다.
3. "잘못 쓰면" 칸을 채워 빈틈을 찾는다.

---

## 1. 개념 — 규칙은 상태에서 나온다

도서관에는 책 한 권마다 **상태**가 있습니다. 대출 가능, 대출 중입니다. 대부분의 규칙은 상태에서 나옵니다.

| 생활 속 규칙 | 상태로 바꾼 말 | 요구사항 |
|---|---|---|
| 빌려 간 책은 다른 사람이 못 빌린다 | 대출 중이면 대출할 수 없다 | 대출 중인 책을 빌리려 하면 오류 |
| 빌리지 않은 책은 반납할 수 없다 | 대출 가능이면 반납할 수 없다 | 대출 가능한 책을 반납하려 하면 오류 |
| 빌리는 사람 이름이 있어야 한다 | 이름이 비면 대출할 수 없다 | 이름이 공백이면 오류 |

> 1단계 2장의 "잘못 쓰면" 칸이 여기서 가장 중요합니다. 규칙마다 **잘못된 경우**가 하나씩 있습니다.

---

## 2. 따라 하기

### 1단계. 생활 규칙 찾기 (15분)

도서관에 가면 볼 수 있는 규칙을 다섯 개 적습니다. 예: "책은 한 번에 한 권만 빌린다", "반납 기한이 있다".

| 생활 속 규칙 | 이 프로그램에서 다룰까? (예/아니오) | 아니오면 이유 |
|---|---|---|
| | | |

### 2단계. 요구사항 틀 채우기 (40분)

1단계 틀 `templates\REQ_빈칸.md` 를 복사합니다.

**[PS]**

```powershell
New-Item -ItemType Directory C:\harness-lab\library-req
Copy-Item C:\harness-beginner-tutorial\templates\REQ_빈칸.md C:\harness-lab\library-req\요구사항.md
notepad C:\harness-lab\library-req\요구사항.md
```

다음 기능을 채웁니다.

- **R1. 책 등록** (제목, 지은이)
- **R2. 목록 보기** (전체, 대출 가능, 대출 중)
- **R3. 대출** (번호와 빌리는 사람 이름)
- **R4. 반납** (번호)
- **R5. 파일 저장과 읽기**

R3, R4 에는 반드시 "잘못 쓰면" 칸을 채웁니다.

- R3: 없는 번호, 이미 대출 중, 이름이 공백
- R4: 없는 번호, 대출 중이 아닌 책

### 3단계. 빈칸 점검하기 (20분)

아래 질문으로 점검합니다.

- [ ] "책 목록" 같은 흐린 말이 있나? 어떤 목록인지 상태로 말했나?
- [ ] 반납하면 빌린 사람 이름은 어떻게 되나? 요구사항에 적혀 있나?
- [ ] 책 번호는 어떻게 정해지나? 지우는 기능이 있으면 번호는 어떻게 되나?
- [ ] "만들지 않는 것"을 적었나? (연체, 날짜 계산 등)

> 세 번째 질문이 함정입니다. 4교시와 5교시에서 이 빈틈이 다시 나옵니다.

### 4단계. 옆 사람과 바꿔 읽기 (25분)

옆 사람의 요구사항에서 **"반납하면 빌린 사람 이름은 어떻게 되나요?"** 같은 질문을 하나씩 찾아 적습니다. 대답이 없으면 그 요구사항은 빈틈이 있는 것입니다.

---

## 3. 확인하기
- [ ] 상태(대출 가능, 대출 중)가 요구사항에 명확히 적혀 있다.
- [ ] R3, R4 의 "잘못 쓰면" 칸이 모두 채워져 있다.
- [ ] 반납 시 빌린 사람 이름이 어떻게 되는지 요구사항에 적혀 있다.

## 4. 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| "관리를 잘한다" 같은 흐린 말이 나온다 | 상태로 바꾼다. 예: "대출 중인 책 목록을 보여 준다" |
| 반납 후 상태를 빠뜨렸다 | 반납 전과 후의 상태를 한 줄씩 적는다. |

## 5. 확인 문제
1. 대출 중인 책을 다시 빌리려 하면 어떤 결과가 나와야 하나? 요구사항에서 찾아 적으시오.
2. 반납하면 `borrower`(빌린 사람)는 무엇이 되어야 하나?
3. 요구사항에 "연체"를 넣지 않은 이유를 "만들지 않는 것"과 연결해서 설명하시오.
