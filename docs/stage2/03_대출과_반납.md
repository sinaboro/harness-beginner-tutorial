## 3단계. AI 에게 지시서 건네고 계획 검토하기 (25분)

**[컨테이너]**

```bash
cd /workspace/library
opencode
```

**[AI]**

```text
TASK_대출반납.md 를 읽고 그 지시대로 작업해 줘. 먼저 계획만 말하고 내 승인을 기다려.
```

계획을 아래 네 질문으로 검토합니다.

| 질문 | 답 (예/아니오) | 아니오면 입력할 문장 |
|---|---|---|
| 1. 연체 계산이나 날짜 계산이 계획에 없는가? | | 아래 문장 A |
| 2. 계획에 lend_book 과 return_book 이 모두 있는가? | | 아래 문장 A |
| 3. 계획에 tests/ 를 고친다는 말이 없는가? | | 아래 문장 A |
| 4. 계획이 library.py 한 개만 고치겠다고 하는가? | | 아래 문장 A |

**[AI] 문장 A** (아니오일 때, 번호만 바꿔 입력합니다)

```text
계획 [번호]번이 TASK_대출반납.md 와 맞지 않아. 그 부분을 빼고 계획을 다시 말해 줘. 아직 파일은 고치지 마.
```

모두 예이면 입력합니다.

**[AI]**

```text
진행
```

끝나면 `/exit` 를 칩니다.

## 4단계. 초록 확인하고 테스트 파일 대조하기 (15분)

**[컨테이너]**

```bash
cd /workspace/library
python -m pytest tests/test_books.py tests/test_lending.py
diff tests/test_lending.py /tutorial/templates/stage2/tests/test_lending.py && echo "테스트 파일은 원본과 같습니다"
```

확인 기준:

| 확인할 것 | 기대하는 결과 | 실제 결과 (예/아니오) |
|---|---|---|
| 테스트 결과 | `13 passed` 가 나온다 | |
| 테스트 파일 | "테스트 파일은 원본과 같습니다"가 나온다 | |

아니오가 있으면 AI 에게 실패 줄을 알리고 `library.py` 만 고치게 합니다. 테스트 파일이 바뀌었다면 원본을 다시 복사합니다.

## 5단계. 상태 규칙을 직접 실행해서 확인하기 (20분)

테스트가 통과해도, 규칙이 눈에 보이는지 직접 확인합니다.

**[컨테이너]**

```bash
cd /workspace/library
python -c "
from library import add_book, lend_book, return_book
books = []
add_book(books, '데미안', '헤세')
print('1. 처음 상태:', books[0]['status'], books[0]['borrower'])
lend_book(books, 1, '철수')
print('2. 대출 후:', books[0]['status'], books[0]['borrower'])
try:
    lend_book(books, 1, '영희')
    print('3. 다시 빌림: 오류가 없었다 (잘못됨)')
except ValueError as e:
    print('3. 다시 빌림: 오류 =', e)
return_book(books, 1)
print('4. 반납 후 상태:', books[0]['status'])
"
```

확인 기준:

| 줄 | 기대하는 결과 | 실제 출력 (그대로 옮긴다) | 맞는가? (예/아니오) |
|---|---|---|---|
| 1 | 처음 상태: available None | | |
| 2 | 대출 후: lent 철수 | | |
| 3 | 다시 빌림: 오류 = (오류 문장) | | |
| 4 | 반납 후 상태: available | | |

오류 문장의 글자는 AI 가 만든 것에 따라 달라도 됩니다. 중요한 것은 3번 줄에 "오류 ="가 있는 것입니다. 아니오가 있으면 AI 에게 그 줄 번호를 알리고 고치게 합니다.

## 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `AttributeError: module 'library' has no attribute 'lend_book'` | AI 가 `lend_book` 을 만들지 않았다. AI 에게 함수 이름을 알리고 추가하게 한다. |
| 직접 실행 3번 줄에 "오류가 없었다"가 나온다 | 이미 대출 중인 책을 막는 검사가 없다. AI 에게 "이미 대출 중이면 ValueError 를 일으키게 해 줘"라고 말한다. |
| `13 passed` 가 아니다 | 실패 줄을 옮겨 적고, AI 에게 원인부터 설명하게 한다. |
