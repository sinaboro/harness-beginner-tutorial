# 2단계 3장. 대출과 반납: 여러 기능을 나눠 맡기기

| | |
|---|---|
| 시간 | 2시간 |
| 준비물 | 2장 완료 (`library.py` 에 책 등록과 저장이 있다) |
| 결과 | 대출과 반납을 AI 에게 맡기고, 상태 규칙이 지켜졌는지 확인해 저장한다 |

## 학습 목표
1. 큰 기능을 작은 지시로 나누는 이유를 말한다.
2. 상태 규칙(대출 중이면 빌릴 수 없다)이 코드에서 어떻게 보이는지 찾는다.
3. 테스트가 정한 기준을 AI 가 지키는지 확인한다.

---

## 1. 개념 — 한 번에 맡기지 않는다

"도서 대출 프로그램 전부 만들어 줘"라고 하면 AI 는 많은 것을 한꺼번에 만듭니다. 그러면 무엇이 잘못됐는지 찾기 어렵습니다.

**작게 나누면**
- 바뀐 코드가 적어서 내가 읽고 이해할 수 있습니다.
- 문제가 생기면 그 지시만 되돌리면 됩니다.
- 테스트가 어느 지시에서 깨졌는지 바로 알 수 있습니다.

> 2장에서 책 등록과 저장을 맡겼습니다. 이번 장은 대출과 반납만 맡깁니다.

---

## 2. 따라 하기

### 1단계. 상태 규칙 테스트 읽기 (20분)

**[PS]**

```powershell
cd C:\harness-lab\library
Copy-Item C:\harness-beginner-tutorial\templates\stage2\tests\test_lending.py tests\
notepad tests\test_lending.py
```

테스트 이름을 목록으로 적습니다. 그다음 아래 질문에 답합니다.

1. 대출 중인 책을 다시 빌리면 어떻게 되어야 하나? (테스트 이름을 찾는다)
2. 대출하지 않은 책을 반납하면 어떻게 되어야 하나?
3. 대출하면 책의 `borrower` 는 무엇이 되나?

### 2단계. 빨강 확인하기 (10분)

**[PS]**

```powershell
python -m pytest tests\test_lending.py
```

`lend_book`, `return_book` 이 없으므로 실패합니다. 실패 줄을 적어 둡니다.

### 3단계. AI 에게 맡기기 (40분)

**[PS]**

```powershell
Copy-Item C:\harness-beginner-tutorial\templates\stage2\TASK_대출반납.md .
opencode
```

**[AI]**

```text
TASK_대출반납.md 를 읽고 그 지시대로 작업해 줘. 먼저 계획만 말하고 내 승인을 기다려.
```

계획에서 확인할 것:

- [ ] 연체나 날짜 계산을 넣겠다는 말이 없는가?
- [ ] `tests/` 를 고치겠다는 말이 없는가?
- [ ] 두 함수가 모두 계획에 있는가? (`lend_book`, `return_book`)

맞으면 `진행` 이라고 답합니다.

### 4단계. 상태 규칙 직접 확인하기 (20분)

AI 가 끝나면 `/exit` 로 나옵니다. 테스트를 돌립니다.

**[PS]**

```powershell
python -m pytest tests\test_books.py tests\test_lending.py
```

모두 통과해야 합니다. 그다음 테스트가 말로 한 규칙을 **직접** 해 봅니다.

**[PS]**

```powershell
python -c "from library import *; b=[]; add_book(b,'데미안','헤세'); lend_book(b,1,'철수'); lend_book(b,1,'영희')"
```

오류가 나와야 합니다. 나오지 않으면 규칙이 지켜지지 않은 것입니다. 원인을 AI 에게 설명하게 합니다.

반납도 해 봅니다.

**[PS]**

```powershell
python -c "from library import *; b=[]; add_book(b,'데미안','헤세'); return_book(b,1)"
```

대출하지 않은 책을 반납하므로 오류가 나와야 합니다.

### 5단계. 규칙을 AI 에게 설명시키기 (15분)

파일을 고치지 말고 설명만 하게 합니다.

**[AI]**

```text
파일은 고치지 말고 설명만 해 줘. library.py 의 lend_book 에서 "이미 대출 중인 책" 을 확인하는 줄이 무슨 일을 해? 그 줄이 없으면 어떤 테스트가 실패해?
```

설명을 읽고, 테스트 이름과 맞는지 확인합니다.

### 6단계. 저장하기 (10분)

**[PS]**

```powershell
python verify.py
git add -A
git status
git commit -m "3장: 대출과 반납, 상태 규칙 (R3, R4)"
```

## 3. 확인하기
- [ ] 두 테스트 파일이 모두 통과했다.
- [ ] 이미 대출 중인 책을 다시 빌리면 오류가 나는 것을 직접 봤다.
- [ ] 저장 커밋이 한 줄 생겼다.

## 4. 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `AttributeError` 또는 `NameError` | AI 가 `_find` 함수를 빠뜨렸다. 실패 줄을 붙여 주고 고치게 한다. |
| 책이 두 번 빌려진다 | 대출 중 확인 줄이 없다. 3단계의 확인 명령을 다시 실행해 증거를 보여 준다. |
| `tests/` 의 파일이 바뀌었다 | `Compare-Object` 로 확인하고, AI 에게 원래대로 되돌리게 한다. |

2. 대출 중인 책을 반납하면 `status` 와 `borrower` 는 각각 무엇이 되나?
3. 테스트가 통과했는데도 내가 직접 규칙을 확인한 이유는 무엇인가?
