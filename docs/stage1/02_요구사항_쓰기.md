## 1단계. 흐린 말 고치기 (15분)

아래 문장에서 흐린 낱말을 찾아 표에 옮기고, 각각을 **눈이나 숫자로 확인할 수 있는 말**로 바꿉니다.

> 계산기는 숫자를 잘 계산하고, 빠르고 정확하며, 사용하기 편해야 한다.

| 흐린 말 | 확인할 수 있는 말로 바꾼 것 (예: "2와 3을 더하면 5가 나온다") |
|---|---|
| 잘 계산한다 | |
| 빠르고 | |
| 정확하며 | |
| 사용하기 편해야 한다 | |

확인 기준: 바꾼 말에 **숫자, 글자, 또는 "나온다/나오지 않는다"** 가 들어 있어야 합니다. 없으면 다시 씁니다.

## 2단계. 요구사항 파일 만들기 (5분)

**[컨테이너]**

```bash
mkdir -p /workspace/req1
cd /workspace/req1
touch 요구사항.md
ls -la
```

**[Windows]** VS Code 에서 `C:\harness-lab\req1\요구사항.md` 를 엽니다.

## 3단계. 워크시트대로 칸 채우기 (40분)

**무엇을:** `요구사항.md` 에 아래 틀을 **그대로** 붙여 넣고, `[ ]` 칸만 채웁니다.

```markdown
# 요구사항: 계산기

## 기능 요구사항

### R1. 더하기
- 이렇게 하면: add(a, b) 를 부른다. a 와 b 는 숫자다.
- 이런 결과가 나온다: [결과 규칙을 한 문장으로. 예: 두 수의 합을 돌려준다. add(2, 3) 은 5 이다.]
- 잘못 쓰면: [잘못된 입력 한 가지와 나오는 결과. 예: 숫자가 아닌 글자를 넣으면 오류가 난다.]

### R2. 빼기
- 이렇게 하면: subtract(a, b) 를 부른다. a 와 b 는 숫자다.
- 이런 결과가 나온다: [결과 규칙. 예: a 에서 b 를 뺀 값을 돌려준다. subtract(10, 4) 는 6 이다.]
- 잘못 쓰면: [잘못된 입력 한 가지와 나오는 결과]

### R3. 나누기
- 이렇게 하면: divide(a, b) 를 부른다. a 와 b 는 숫자다.
- 이런 결과가 나온다: [결과 규칙. 예: a 를 b 로 나눈 값을 돌려준다. divide(9, 3) 은 3 이다.]
- 잘못 쓰면: [b 가 0 일 때 나오는 결과. 예: ValueError 오류를 내고 "0으로 나눌 수 없습니다."라는 글을 보여 준다.]

## 만들지 않는 것
- [이번에 만들지 않을 기능 한 가지. 예: 곱하기]
- [만들지 않을 기능 한 가지. 예: 화면 또는 파일 저장]
```

**칸 채우기 규칙** (대괄호 `[ ]` 칸마다):

| 칸 | 무엇을 쓰나 | 바꾸는 방법 |
|---|---|---|
| R1 "이런 결과가 나온다" | 결과 규칙 한 문장 + 예 한 개 | 예시 문장을 참고해 내 말로 바꾼다 |
| R1 "잘못 쓰면" | 잘못된 입력 한 가지와 결과 | 예시를 참고해 쓴다 |
| R2 "이런 결과가 나온다" | 빼기 규칙 + 예 한 개 | 예: `subtract(10, 4)` 는 6 |
| R2 "잘못 쓰면" | 잘못된 입력 한 가지와 결과 | 숫자가 아닌 글자를 넣는 경우를 쓴다 |
| R3 "이런 결과가 나온다" | 나눗셈 규칙 + 예 한 개 | 예: `divide(9, 3)` 은 3 |
| R3 "잘못 쓰면" | 0으로 나누는 경우의 결과 | 예시 문장을 그대로 써도 된다 |
| "만들지 않는 것" 두 줄 | 이번에 만들지 않을 것 두 개 | 예: 곱하기, 화면 |

하는 법: VS Code 에서 `[` 를 Ctrl+F 로 찾아, 칸의 `[`부터 `]`까지를 내 문장으로 바꿉니다. 대괄호도 함께 지웁니다.

## 4단계. 점검 항목 확인하고 고치기 (25분)

**[컨테이너]**

```bash
cd /workspace/req1
grep -c "\[" 요구사항.md
grep -c "잘못 쓰면" 요구사항.md
grep -c "이런 결과가 나온다" 요구사항.md
```

아래 표의 항목을 한 줄씩 확인합니다.

| 번호 | 확인할 것 | 확인 방법 | 예 / 아니오 |
|---|---|---|---|
| 1 | `[` 가 한 개도 없다 | 첫 명령 결과가 `0` | |
| 2 | "잘못 쓰면"이 세 번 나온다 (R1~R3) | 둘째 명령 결과가 `3` | |
| 3 | "이런 결과가 나온다"가 세 번 나온다 | 셋째 명령 결과가 `3` | |
| 4 | "잘 된다", "빠르다", "정확하다", "편하다"가 없다 | `grep -c "잘 \|빠르\|정확\|편하" 요구사항.md` 결과가 `0` | |
| 5 | "만들지 않는 것" 아래에 두 줄이 있다 | VS Code 에서 그 아래 줄을 세어 본다 | |

아니오가 있으면, 그 줄을 VS Code 에서 고치고 같은 명령을 다시 칩니다. 고친 번호는 옆에 적습니다.

## 5단계. 옆 사람과 바꿔 읽고 질문 적기 (15분)

옆 사람의 `요구사항.md` 를 읽고 질문을 두 개 이상 적습니다. 형식은 아래와 같습니다.

```text
R[번호] 에서 [무엇]이 궁금합니다.
```

질문에 답이 적혀 있지 않으면 그 줄이 빈틈입니다. 빈틈이 있는 줄을 한 문장 더 구체적으로 고칩니다.

## 확인 체크리스트
- [ ] 흐린 말 네 개를 확인할 수 있는 말로 바꿨다.
- [ ] `요구사항.md` 에 `[` 가 0건이다.
- [ ] 4단계의 다섯 항목을 모두 확인하고, 아니오는 고쳤다.
- [ ] 옆 사람 파일에서 질문을 두 개 이상 적었다.

## 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `grep -c "\["` 결과가 0이 아니다 | `grep -n "\[" 요구사항.md` 로 줄 번호를 본다. 그 줄의 대괄호를 지운다. |
| "잘못 쓰면" 개수가 3이 아니다 | 빠진 기능의 "잘못 쓰면" 줄을 추가하거나, 중복된 줄을 지운다. |
| 예시 문장을 그대로 복사했다 | 예시는 참고용이다. 내 말로 한 번 바꾼다. 그래도 같으면 괜찮다. |
