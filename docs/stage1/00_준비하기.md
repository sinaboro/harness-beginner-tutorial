# 0장. 준비하기

| | |
|---|---|
| 시간 | 1시간 |
| 준비물 | Windows PC, 인터넷, 신용카드(OpenRouter 크레딧 충전용) |
| 결과 | Python, Git, OpenCode 가 설치되고, 작업 폴더와 AI 연결이 끝난다 |

이 과정은 **Docker 없이** 진행합니다. PC 에 Python, Git, OpenCode 세 가지만 설치하면 됩니다.
나중에 3단계(3일 과정, Docker 사용)로 올라갈 때 Docker 를 다시 설치합니다.

---

## 1. 설치할 세 가지

| 도구 | 하는 일 | 받는 곳 |
|---|---|---|
| Python 3.12 | 테스트와 프로그램을 실행한다 | https://www.python.org/downloads/ |
| Git for Windows | 변경 기록을 남기고, Git Bash 를 제공한다 | https://git-scm.com/download/win |
| OpenCode | AI 에이전트. 파일을 읽고 고치고 명령을 실행한다 | 아래 3번 |

**Python 설치 때 반드시 체크할 것:** 첫 화면 아래의 **Add python.exe to PATH**. 이걸 빼면 `python` 명령이 인식되지 않습니다.

**Git 설치 때:** 나오는 선택지는 모두 기본값으로 둡니다.

## 2. 설치 확인

PowerShell 을 새로 열고 아래를 칩니다. 버전 번호가 나오면 됩니다.

**[PS]**

```powershell
python --version
git --version
```

```text
Python 3.12.x
git version 2.x.x.windows.x
```

"인식되지 않습니다"가 나오면 PowerShell 창을 닫고 새로 엽니다. 그래도 안 되면 설치를 다시 합니다.

## 3. OpenCode 설치 (Git Bash 에서)

시작 메뉴에서 **Git Bash** 를 열고 아래를 칩니다.

**[Git Bash]**

```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

설치가 끝나면 Git Bash 를 **닫고 다시 엽니다.** 그다음 확인합니다.

**[Git Bash]**

```bash
opencode --version
```

버전 번호가 나오면 됩니다. "command not found"가 나오면 Git Bash 를 새로 열었는지 확인합니다.

> 이 교안은 OpenCode 2.x 를 기준으로 썼습니다. 2.x 가 아닌 버전이 나오면 강사에게 알려 주세요. 권한 설정 파일의 형식이 다를 수 있습니다.

## 4. OpenRouter 계정과 키

OpenRouter 는 여러 회사의 AI 모델을 한 주소, 한 키로 쓰게 해 주는 서비스입니다. 쓴 만큼 요금을 냅니다.

1. https://openrouter.ai 에 가입합니다.
2. **Credits** 메뉴에서 크레딧을 충전합니다. 수업 한 번에 드는 비용은 적지만, 최소 금액으로 시작하세요.
3. **Keys** 메뉴에서 **Create Key** 를 누릅니다. 이름은 `harness-beginner` 로 하고, 사용 한도(Credit limit)를 작게 정합니다.
4. 만들어진 키(`sk-or-v1-` 로 시작)를 복사합니다. **이 화면을 닫으면 다시 볼 수 없습니다.**

> **키는 비밀번호와 같습니다.** 채팅, 화면 공유, 캡처 사진, GitHub 에 올리지 않습니다.

## 5. OpenCode 에 키 연결하기

1. Git Bash 에서 아무 폴더에서나 `opencode` 를 칩니다. OpenCode 화면이 열립니다.
2. 입력 칸에 `/connect` 를 치고 Enter 를 누릅니다.
3. 목록에서 **OpenRouter** 를 고르고, 복사한 키를 붙여 넣습니다.
4. `/models` 를 쳐서 모델 목록이 나오면 연결이 된 것입니다.
5. `/exit` 로 나옵니다.

## 6. 작업 폴더와 설정 파일 받기

모든 실습은 `C:\harness-lab` 에서 합니다. 교안의 예제와 템플릿은 저장소에서 받습니다.

**[PS]**

```powershell
git clone https://github.com/sinaboro/harness-beginner-tutorial C:\harness-beginner-tutorial
New-Item -ItemType Directory C:\harness-lab
python -m pip install pytest
git config --global user.name "본인 이름"
git config --global user.email "본인 메일"
```

`git config` 두 줄은 한 번만 하면 됩니다. 커밋할 때 누가 저장했는지 기록됩니다.

확인합니다.

**[PS]**

```powershell
python -m pytest --version
dir C:\harness-beginner-tutorial
```

`pytest 9.x` 가 나오고, `docs`, `examples`, `templates` 폴더가 보이면 준비가 끝났습니다.

## 확인 체크리스트

- [ ] `python --version` 에 3.12 이상이 나온다
- [ ] `git --version` 이 나온다
- [ ] Git Bash 에서 `opencode --version` 이 나온다
- [ ] OpenCode 에서 `/models` 를 쳤을 때 목록이 나온다
- [ ] `C:\harness-lab` 폴더가 있다
- [ ] `C:\harness-beginner-tutorial\templates` 폴더가 있다

## 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `python` 이 인식되지 않는다 | Python 설치 때 PATH 체크를 빠뜨렸다. Python 을 다시 설치하거나 `py` 명령을 쓴다. 이 교안은 `python` 으로 쓴다. |
| `python -m pip install pytest` 가 권한 오류를 낸다 | PowerShell 을 관리자 권한으로 열지 말고, `python -m pip install --user pytest` 를 쓴다. |
| `/models` 목록이 비어 있다 | 키를 잘못 붙였거나 크레딧이 없다. OpenRouter 의 Keys 와 Credits 화면을 확인한다. |
| OpenCode 설치 명령이 실패한다 | 명령을 Git Bash 에서 쳤는지 확인한다. PowerShell 에서 치면 실패한다. |
