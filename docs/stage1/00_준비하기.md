# 1단계 준비하기 (도커)

| | |
|---|---|
| 시간 | 1시간 30분 (처음 한 번) |
| 준비물 | Windows 10·11, Docker Desktop, Git for Windows, VS Code, 인터넷, OpenRouter 계정 |
| 결과 | 도커 컨테이너 안에 Python, pytest, Git, OpenCode 가 준비되고, OpenRouter 에 연결된다 |

1단계부터 Python 을 씁니다. 그래도 **PC 에 Python 을 설치하지 않습니다.** Python 은 컨테이너 안에 들어 있습니다.

> **역할 나누기**
> - **Windows 쪽(PowerShell)**: 설치하고, 저장소를 받고, 컨테이너를 켠다. `[Windows]` 표시.
> - **컨테이너 쪽(bash)**: 교안의 실습 명령을 친다. `[컨테이너]` 표시.
> - **편집과 확인**: Windows 의 VS Code 에서 파일을 고친다.

---

## 1. Docker Desktop 설치 (Windows)

1. https://www.docker.com/products/docker-desktop/ 에서 받아 설치합니다.
2. 설치 중 **Use WSL 2 instead of Hyper-V** 가 보이면 체크된 채로 둡니다.
3. PC 를 재시작하고 Docker Desktop 을 실행합니다. **Engine running** 이 될 때까지 기다립니다.

**[Windows]** (PowerShell)

```powershell
docker version
```

Client 와 Server 두 줄이 모두 나와야 합니다.

## 2. 저장소 받기와 설정 파일 (Windows)

**[Windows]** (PowerShell)

```powershell
git clone https://github.com/sinaboro/harness-beginner-tutorial C:\harness-beginner-tutorial
New-Item -ItemType Directory C:\harness-lab
cd C:\harness-beginner-tutorial\docker
Copy-Item .env.example .env
```

VS Code 로 `C:\harness-beginner-tutorial\docker\.env` 를 열어 `GIT_NAME` 과 `GIT_EMAIL` 을 본인 것으로 바꾸고 저장합니다.

## 3. 작업 환경 만들기 (Windows, 처음 한 번)

**[Windows]** (PowerShell)

```powershell
cd C:\harness-beginner-tutorial\docker
docker compose build
```

처음에는 몇 분 걸립니다. 마지막에 `Built` 또는 `Successfully` 가 보이면 됩니다.

## 4. 컨테이너 들어가기 (Windows)

**[Windows]** (PowerShell)

```powershell
docker compose run --rm workspace
```

프롬프트가 `root@…:/workspace#` 로 바뀌면 컨테이너 안입니다. 확인합니다.

**[컨테이너]**

```bash
pwd
python --version
python -m pytest --version
git --version
opencode --version
```

`/workspace` 는 Windows 의 `C:\harness-lab` 과 같은 폴더이고, `/tutorial` 에는 교안의 템플릿과 예제가 있습니다(읽기 전용).

## 5. OpenRouter 연결 (컨테이너 안)

**[컨테이너]**

```bash
opencode
```

입력 칸에 `/connect` 를 치고 **OpenRouter** 를 고른 뒤 키를 붙여 넣습니다. `/models` 로 목록이 나오면 `/exit` 로 나옵니다.

> 키는 도커 볼륨에 남습니다. 다음에 다시 들어가도 연결은 그대로입니다.

## 6. 작업 폴더 확인

**[컨테이너]**

```bash
mkdir -p /workspace/calc
ls -la /workspace
```

Windows 탐색기에서 `C:\harness-lab\calc` 가 보이면 연결이 된 것입니다.

---

## 확인 체크리스트
- [ ] `docker version` 에 Server 가 나온다 (Windows)
- [ ] 컨테이너 안에서 `python --version` 과 `python -m pytest --version` 이 나온다
- [ ] 컨테이너 안에서 `opencode` → `/models` 목록이 나온다
- [ ] Windows 의 `C:\harness-lab\calc` 가 보인다

## 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `error during connect` | Docker Desktop 이 Engine running 이 아니다. 기다리거나 재시작한다. |
| `/workspace` 가 비어 있다 | `.env` 의 `HARNESS_LAB_DIR` 이 틀렸다. 슬래시로 쓰고 폴더가 있는지 본다. |
| `pytest` 가 파일을 못 찾는다 | 명령을 친 폴더가 맞는지 `pwd` 로 확인한다. 과제 폴더(`/workspace/calc` 등)에서 실행한다. |
| `git commit` 이 `Please tell me who you are` | `.env` 의 `GIT_NAME`, `GIT_EMAIL` 을 채우고 컨테이너를 다시 들어간다. |

자세한 설명은 [도커로 실행하기](../docker/00_도커로_실행하기.md)를 봅니다.
