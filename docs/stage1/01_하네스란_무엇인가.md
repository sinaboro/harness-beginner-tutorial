# 1단계 1장. 하네스란 무엇인가: 같은 부탁, 다른 결과

> **실행 환경: 도커.** 명령 블록은 컨테이너 안(bash)에서 칩니다. `[Windows]` 로 표시된 블록만 Windows PowerShell 에서 칩니다. 파일 편집은 Windows 의 VS Code 에서 합니다. 자세한 설명은 [도커로 실행하기](../docker/00_도커로_실행하기.md)를 봅니다.

| | |

| 준비물 | 1단계 00 준비하기를 마친 상태 (`opencode` 가 `/models` 목록을 보여 준다) |
| 결과 | 조건 없이 시킨 결과와 조건을 붙여 시킨 결과를 표로 비교하고, 차이를 한 문장으로 말한다 |

## 이 장에서 할 일 한눈에 보기

1. 실험 A 폴더를 만들고, AI 에게 한 줄로 시킨다. (15분)
2. 실험 A 의 결과를 확인하고 표 A 를 채운다. (25분)

## 1단계. 실험 A: 조건 없이 한 줄로 시키기 (15분)

**[컨테이너]**

```bash
mkdir -p /workspace/lesson01
cd /workspace/lesson01
opencode
```

OpenCode 입력 칸에 아래 문장을 **그대로** 붙여 넣고 Enter 를 누릅니다. 다른 말은 덧붙이지 않습니다.

**[AI]**

```text
두 수를 더하고 빼는 계산기 파일 calc.py 를 만들어 줘.
```

AI 가 끝낼 때까지 기다립니다. 끝나면 입력 칸에 `/exit` 를 치고 Enter 를 누릅니다.

## 2단계. 실험 A 결과 확인하고 표 A 채우기 (25분)

**[컨테이너]**

```bash
cd /workspace/lesson01
ls -la
python calc.py
```

**무엇을:** 아래 표의 칸마다 확인 방법대로 보고 적습니다.

| 항목 | 확인 방법 | 내가 적은 답 |
|---|---|---|
| 1. 만들어진 파일 이름은? | `ls -la` 결과의 파일 이름을 모두 적는다 | |
| 2. 파일이 몇 개인가? | `ls -la` 결과에서 `.` 과 `..` 을 빼고 센다 | |
| 3. `calc.py` 에 나눗셈(`/`)이 있는가? | VS Code 에서 `calc.py` 를 열고 Ctrl+F 로 `/` 를 찾는다. 있으면 "있음" | |
| 4. 0으로 나눌 때를 막는 검사(`== 0`)가 있는가? | VS Code 에서 Ctrl+F 로 `== 0` 을 찾는다. 있으면 "있음" | |
| 5. 테스트 파일이 있는가? | `ls -la` 결과에 `tests` 또는 `test_` 이름이 있는지 본다 | |
| 6. 시키지 않은 것(나눗셈, 곱셈 등)이 있는가? | 3번 결과를 보고 "있음/없음" | |
| 7. AI 가 작업 전에 계획을 말했는가? | 대화 화면을 위로 올려 "계획" 단어가 있는지 본다 | |

확인 기준: `python calc.py` 를 실행하면 아무것도 출력되지 않거나 그냥 끝나야 정상입니다. 오류가 나도 그 오류 문장을 표 밑에 그대로 옮겨 적습니다.

## 3단계. 실험 B: 조건 세 개를 붙여 시키기 (25분)

**[컨테이너]**

```bash
mkdir -p /workspace/lesson01b
cd /workspace/lesson01b
opencode
```

**[AI]**

```text
두 수를 더하고 빼는 계산기 파일 calc.py 를 만들어 줘.
조건 1. 파일은 calc.py 하나만 만든다. 다른 파일은 만들지 않는다.
조건 2. 더하기(add)와 빼기(subtract) 함수만 만든다. 다른 기능은 추가하지 않는다.
조건 3. 파일을 고치기 전에 계획을 먼저 말하고, 내가 "진행"이라고 할 때까지 기다린다.
```

AI 가 계획을 말하면, 계획에 "나눗셈" 또는 "곱셈"이 있는지 봅니다.
- 있다: 아래 문장을 그대로 입력합니다. `[번호]` 는 계획의 해당 줄 번호로 바꿉니다.
- 없다: 아래 문장만 입력합니다.

**[AI]**

```text
계획 [번호]번은 조건 2에 어긋나. 그 부분을 빼고 계획을 다시 말해 줘.
```

**[AI]**

```text
진행
```

끝나면 `/exit` 를 칩니다.

## 4단계. 표 B 채우고 표 A 와 비교하기 (20분)

**[컨테이너]**

```bash
cd /workspace/lesson01b
ls -la
python calc.py
```

표 B 는 표 A 와 **같은 번호, 같은 확인 방법**으로 채웁니다.

| 항목 | 표 A (1단계에서 적은 답) | 표 B (이번 답) | 같은가, 다른가 |
|---|---|---|---|
| 1. 파일 이름 | | | |
| 2. 파일 개수 | | | |
| 3. 나눗셈(`/`)이 있는가? | | | |
| 4. 0 나누기 검사(`== 0`)가 있는가? | | | |
| 5. 테스트 파일이 있는가? | | | |
| 6. 시키지 않은 것이 있는가? | | | |
| 7. 계획을 먼저 말했는가? | | | |

비교 기준:
- 같은 번호의 두 칸을 읽고, 같으면 "같음", 다르면 "다름"을 네 번째 칸에 적습니다.
- "다름"이 가장 많은 항목 한 개에 동그라미를 칩니다.

## 5단계. 조건 세 개가 막으려는 것 적기 (15분)

실험 B 의 조건 세 개가 **각각 무엇을 막으려고 한 것인지** 한 문장으로 적습니다.

| 조건 | 막으려는 것 (한 문장) |
|---|---|
| 조건 1 (파일 하나만) | |
| 조건 2 (더하기와 빼기만) | |
| 조건 3 (계획 먼저) | |

확인 기준: 각 문장에 "~하지 못하게" 또는 "~이 생기지 않게"의 뜻이 있어야 합니다. 없으면 다시 씁니다.

## 확인 체크리스트

- [ ] 다름이 가장 많은 항목에 동그라미를 쳤다.

## 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `opencode` 가 "모델을 선택하세요"라고 한다 | 00 준비하기 5번의 `/connect` 를 다시 한다. |
| 실험 B 에서 AI 가 계획 없이 바로 만든다 | 조건 3 을 바꾸지 않고 다시 입력한다. 이미 만들었다면 `/undo` 를 친다. |
| `python calc.py` 에서 오류가 난다 | 오류 문장을 표 밑에 그대로 옮긴다. 2장과 5장에서 이런 오류를 다룬다. |
