# 1교시. 하네스란 무엇인가 — 같은 부탁, 다른 결과

> **실행 환경: 도커.** 명령 블록은 컨테이너 안(bash)에서 칩니다. `[Windows]` 로 표시된 블록만 Windows PowerShell 에서 칩니다. 파일 편집은 Windows 의 VS Code 에서 합니다. 자세한 설명은 [도커로 실행하기](../docker/00_도커로_실행하기.md)를 봅니다.

| | |
|---|---|
| 시간 | 2시간 |
| 준비물 | 0장 완료 (OpenCode 가 OpenRouter 에 연결된 상태) |
| 결과 | 하네스가 있을 때와 없을 때의 차이를 내 눈으로 확인한다 |

## 학습 목표

1. AI 모델, AI 에이전트, 도구, 하네스를 한 문장씩 구분한다.
2. 같은 부탁을 두 가지 방식으로 해 보고, 결과가 어떻게 달라지는지 기록한다.
3. 하네스의 다섯 요소(규칙, 도구, 권한, 실행, 검증)를 말할 수 있다.

## 1. 개념 — 네 가지 낱말

| 낱말 | 한 문장 설명 | 비유 |
|---|---|---|
| AI 모델 | 글을 받아 글을 돌려준다. 파일을 보지 못하고 명령도 실행하지 못한다. | 전화로만 대답하는 똑똑한 상담원 |
| AI 에이전트 | 모델의 말대로 파일을 읽고 고치고 명령을 실행하는 프로그램. 이 교안에서는 OpenCode. | 상담원의 지시를 받아 내 책상에서 일하는 직원 |
| 도구 | 에이전트가 일할 때 쓰는 것. 파일 읽기, 명령 실행, 테스트 실행기 등. | 직원이 쓰는 망치와 줄자 |
| 하네스 | 에이전트의 일을 통제하는 장치 전체. | 말에게 씌우는 마구(고삐와 안장) |

> **하네스(harness)** 는 원래 말에게 씌우는 마구입니다. 말은 힘이 세고 빠르지만, 마구가 없으면 원하는 방향으로 달릴 수 없습니다. 마구는 말의 힘을 줄이는 것이 아니라, 힘을 쓸모 있게 만드는 것입니다. AI 에이전트도 같습니다.

### 바이브 코딩과 하네스 엔지니어링

| | 바이브 코딩 | 하네스 엔지니어링 |
|---|---|---|
| 시키는 방법 | "메모 앱 만들어 줘" | 요구사항과 작업 지시서를 쓴다 |
| 결과의 확인 | 돌아가는 것 같으면 OK | 테스트를 돌려 통과했는지 본다 |
| AI 가 할 수 있는 일 | 무엇이든 | 허락한 것만 |
| 끝난 뒤 | 내가 설명할 수 없는 코드가 남는다 | 읽고 설명할 수 있는 코드가 남는다 |

### 하네스의 다섯 요소

| 요소 | 질문 | 이 교안에서 만나는 것 |
|---|---|---|
| 규칙 | 어떻게 일해야 하나? | `AGENTS.md` (4장) |
| 도구 | 무엇으로 일하나? | Python, pytest, Git |
| 권한 | 어디까지 해도 되나? | `opencode.jsonc` (4장) |
| 실행 | 어디에서 실행되나? | 작업 폴더 `/workspace` |
| 검증 | 다 됐는지 어떻게 아나? | `verify.py` 와 테스트 (5장) |

## 2. 따라 하기

### 1단계. 실험 폴더 만들기

**[컨테이너]**

```bash
mkdir -p /workspace/lesson01
cd /workspace/lesson01
opencode
```

OpenCode 화면이 열립니다. 이 폴더가 AI 가 볼 수 있는 전부입니다.

### 2단계. 실험 A — 아무 규칙 없이 한 줄로 시키기

OpenCode 입력 칸에 아래를 그대로 붙여 넣고 Enter 를 누릅니다.

**[AI]**

```text
두 수를 더하고 빼는 계산기 파일 calc.py 를 만들어 줘.
```

AI 가 일을 끝낼 때까지 기다립니다. 그다음 아래 표를 채웁니다. (`/exit` 로 나온 뒤 컨테이너 셸에서 `ls` 과 `type calc.py` 로 확인해도 됩니다.)

| 관찰할 것 | 내 기록 |
|---|---|
| 고치기 전에 계획을 말했나? | |
| 파일을 몇 개 만들었나? 이름은? | |
| 나눗셈 같은 기능을 추가했나? 시키지 않았는데? | |
| 0으로 나누는 경우를 생각했나? | |
| 테스트 파일을 만들었나? | |
| 실행해서 확인했나? | |

`/exit` 로 나온 뒤, 만들어진 파일을 실행해 봅니다.

**[컨테이너]**

```bash
python calc.py
```

화면에 아무 일도 없거나 오류가 나도 괜찮습니다. 이 실험의 목적은 **AI 가 무엇을 멋대로 정했는지** 보는 것입니다.

### 3단계. 실험 B — 같은 목표를, 조건을 붙여서

폴더를 새로 만듭니다.

**[컨테이너]**

```bash
mkdir -p /workspace/lesson01b
cd /workspace/lesson01b
opencode
```

OpenCode 에 이번에는 조건 세 가지를 붙여서 시킵니다.

**[AI]**

```text
두 수를 더하고 빼는 계산기 파일 calc.py 를 만들어 줘.
조건 1. 파일은 calc.py 하나만 만든다. 다른 파일은 만들지 않는다.
조건 2. 더하기(add)와 빼기(subtract) 함수만 만든다. 다른 기능은 추가하지 않는다.
조건 3. 파일을 고치기 전에 계획을 먼저 말하고, 내가 "진행"이라고 할 때까지 기다린다.
```

AI 가 계획을 말하면 읽어 보고, 괜찮으면 `진행` 이라고 답합니다. 끝난 뒤 같은 표를 채웁니다. 두 실험의 차이를 아래 표에 적습니다.

| 관찰할 것 | 실험 A (한 줄) | 실험 B (조건 붙임) |
|---|---|---|
| 계획을 먼저 말했나? | | |
| 파일 개수 | | |
| 시키지 않은 기능이 있나? | | |
| 0으로 나누기를 다뤘나? | | |

### 4단계. 차이를 말로 설명하기

실험 B 에서 조건 세 개는 **무엇을 막으려고** 붙인 것인지 생각합니다.

| 조건 | 막으려는 것 |
|---|---|
| 조건 1 (파일 하나만) | |
| 조건 2 (기능 두 개만) | |
| 조건 3 (계획 먼저) | |

조건으로 적은 문장이 바로 **하네스의 규칙(부탁)** 입니다. 4장에서 이런 문장을 `AGENTS.md` 로 옮겨 적습니다.

## 4. 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| `opencode` 가 실행되지 않는다 | 컨테이너 셸에서 실행하는지 확인한다. |
| AI 가 "모델을 선택하세요"라고 한다 | `/connect` 로 OpenRouter 키를 연결한다(0장 5절). |
| AI 가 계획 없이 바로 파일을 만든다 | 조건 3 을 다시 붙여 넣는다. 이 단계에서는 규칙이 없으니 정상입니다. |
| `python calc.py` 에서 오류가 난다 | 오류 내용을 적어 둔다. 2장과 5장에서 이런 오류를 다룹니다. |

## 5. 확인 문제

1. AI 모델과 AI 에이전트의 차이를 "파일"이라는 낱말을 넣어 설명하시오.
2. 실험 A 에서 AI 가 시키지 않은 것을 했다면, 무엇이었나?
3. 조건 3(계획 먼저)이 없으면 어떤 위험이 생기는가?
4. 하네스의 다섯 요소를 쓰시오.
5. 같은 부탁을 여러 번 해도 결과가 똑같지 않은 이유를 한 문장으로 쓰시오.
