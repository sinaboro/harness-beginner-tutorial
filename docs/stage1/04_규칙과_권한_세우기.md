3. `opencode.jsonc` 의 규칙을 읽고, 허용·질문·금지가 실제로 어떻게 작동하는지 확인한다.

## 1. 개념 — 부탁과 잠금장치

3장에서는 지시서를 매번 건넸습니다. 같은 내용을 매번 말하지 않으려고 규칙을 파일로 적어 둡니다.

| | 규칙 (`AGENTS.md`) | 권한 (`opencode.jsonc`) |
|---|---|---|
| 성격 | 부탁 | 잠금장치 |
| 어떻게 작동하나 | AI 가 읽고 따른다 | 금지된 일은 실행 자체가 막힌다 |
| 잊거나 어기면? | 어길 수 있다 | 막힌다 |
| 예 | "커밋은 하지 않는다" | `git commit` 을 deny 로 막는다 |

> 교실 문에 "들어가지 마시오"라고 써 붙이는 것(규칙)과, 문을 잠그는 것(권한)의 차이입니다. 둘 다 있어야 합니다. 써 붙여야 이유를 알고, 잠가야 확실히 막힙니다.

### 권한 규칙 읽는 법

```jsonc
{ "action": "shell", "resource": "git commit *", "effect": "deny" }
```

| 칸 | 뜻 | 예 |
|---|---|---|
| action | 무엇을 하려는가 | `shell`(명령 실행), `edit`(파일 고치기), `read`(파일 읽기) |
| resource | 무엇에 대해서인가 | `git commit *` (`*` 는 "아무 글자나") |
| effect | 어떻게 처리하나 | `allow`(그냥 허용), `ask`(나에게 묻기), `deny`(금지) |

**규칙은 위에서 아래로 읽고, 가장 아래에 걸린 규칙이 이깁니다.** 그래서 넓은 규칙은 위에, 예외는 아래에 씁니다.

### 4단계. 권한이 실제로 막는지 확인하기 (30분)

이제 AI 에게 막혀야 할 일을 일부러 시킵니다. 먼저 연습용 `.env` 파일을 만듭니다. 값은 실제 키가 아닌 연습용 문자열입니다.

**[PS]**

```powershell
cd C:\harness-lab\calc
Set-Content .env "TEST_SECRET=연습용-값입니다"
git init
opencode
```

OpenCode 에서 아래를 하나씩 시키고, 결과를 표에 적습니다.

**[AI]**

```text
.env 파일을 읽고 안에 무슨 변수가 있는지 알려 줘.
```

**[AI]**

```text
git commit -m "test" 를 실행해 줘.
```

**[AI]**

```text
tests/test_calc.py 의 첫 줄에 주석을 한 줄 추가해 줘.
```

**[AI]**

```text
python --version 명령을 실행해 줘.
```

| 시킨 일 | 기대하는 결과 | 실제 결과 |
|---|---|---|
| `.env` 읽기 | 막힌다 (deny) | |
| `git commit` 실행 | 막힌다 (deny) | |
| `tests/` 고치기 | 막힌다 (deny) | |
| `python --version` 실행 | 나에게 묻는다 (ask) | |

`ask` 에 걸리면 OpenCode 가 허락을 구합니다. 이때 고를 수 있는 답은 다음과 같습니다.

| 답 | 뜻 |
|---|---|
| once | 이번 한 번만 허락 |
| always | 앞으로 같은 요청은 묻지 않음 (이 교안에서는 쓰지 않는다) |
| reject | 허락하지 않음 |

이 교안에서는 `once` 또는 `reject` 만 고릅니다.

`/exit` 로 나온 뒤 확인합니다.

**[PS]**

```powershell
git status
git log --oneline
```

커밋이 생기지 않았고, `tests/test_calc.py` 가 바뀌지 않았다면 권한이 제대로 작동한 것입니다. 기대와 다르면 강사에게 알려 주세요.

### 5단계. 규칙은 어떻게 작동하나 (15분)

`AGENTS.md` 를 맨 위 폴더에 두면 OpenCode 는 시작할 때 읽습니다. 규칙이 실제로 작동하는지 확인합니다.

OpenCode 를 새로 열고, 규칙에 적은 내용을 **말하지 않고** 물어봅니다.

**[AI]**

```text
이 프로젝트에서 작업할 때 지켜야 할 규칙이 뭐야? 파일을 고치지 말고 말로만 알려 줘.
```

AI 가 `AGENTS.md` 의 내용을 말하는지 확인합니다. 말하지 못하면 파일 위치나 이름을 다시 확인합니다.

## 3. 확인하기

- [ ] `AGENTS.md` 에 체크리스트 다섯 문장이 모두 들어 있다.
- [ ] `opencode.jsonc` 의 규칙 다섯 개를 말로 설명할 수 있다.

## 4. 자주 만나는 오류

| 증상 | 해결 |
|---|---|
| OpenCode 가 `AGENTS.md` 를 읽지 않는다 | 파일이 `C:\harness-lab\calc` 맨 위에 있는지 확인한다. `/exit` 후 다시 연다. |
| 설정을 바꿨는데 막히지 않는다 | OpenCode 를 새로 열었는지 확인한다. `opencode.jsonc` 의 쉼표와 따옴표를 확인한다. |
| `git init` 이 안 된다 | Git 설치를 확인한다(`git --version`). |
| `.env` 를 AI 가 읽어서 내용을 보여 준다 | 권한 설정이 적용되지 않은 것이다. 설정 파일이 `calc` 폴더에 있는지 확인하고 OpenCode 를 다시 연다. 그래도 안 되면 강사에게 알린다. |
