# 작업 지시서: 대출과 반납 (2단계 3장)

## 1. 목표
책을 빌려 주고 돌려받는 기능을 `library.py` 에 추가한다. 상태 규칙을 지키는 것이 핵심이다.

## 2. 요구사항
`REQUIREMENTS.md` 의 **R3, R4** 를 구현한다. (R1, R2, R5 는 이미 되어 있다)

## 3. 범위
- 고쳐도 되는 파일: `library.py` 하나뿐이다.
- 고치면 안 되는 파일: `tests/` 폴더 전체, `verify.py`, `AGENTS.md`, `opencode.jsonc`

## 4. 하지 말 것
- 연체, 날짜 계산을 만들지 않는다. (대출 기간은 이번 장에서 넣지 않는다)
- 대출 기록을 따로 파일로 남기지 않는다.
- 테스트 기대값을 바꾸거나, 테스트를 건너뛰게 만들지 않는다.

## 5. 완료 조건
- [ ] `python -m pytest tests/test_books.py tests/test_lending.py` 가 모두 통과한다.
- [ ] `tests/` 폴더는 바뀌지 않았다.
- [ ] 이미 대출 중인 책을 다시 빌리려 하면 오류가 나고, 상태는 바뀌지 않는다. (내가 직접 확인한다)

## 6. 진행 방법
`AGENTS.md` 의 작업 순서를 따른다. 먼저 계획을 말하고, 내가 "진행"이라고 하면 구현한다.
계획에 테스트 파일 수정이 들어 있으면 그 줄을 빼게 한 뒤 승인한다.
