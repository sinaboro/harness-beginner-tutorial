# 작업 지시서: 책 등록과 파일 저장 (2단계 2장)

## 1. 목표
책을 등록하고, 목록을 보고, JSON 파일에 저장하고 읽어 올 수 있는 `library.py` 의 앞부분을 만든다.

## 2. 요구사항
`REQUIREMENTS.md` 의 **R1, R2, R5** 를 구현한다. (R3, R4 는 이번에 만들지 않는다)

## 3. 범위
- 새로 만드는 파일: `library.py` 하나
- 고쳐도 되는 파일: `library.py` 하나뿐이다.
- 고치면 안 되는 파일: `tests/` 폴더 전체, `verify.py`, `AGENTS.md`, `opencode.jsonc`

## 4. 하지 말 것
- `lend_book`, `return_book` 을 만들지 않는다. (3장에서 한다)
- 웹 화면, 데이터베이스, 외부 패키지를 쓰지 않는다. 파이썬 기본 기능만 쓴다.
- 책 삭제나 수정 기능을 덧붙이지 않는다.

## 5. 완료 조건
- [ ] `python -m pytest tests/test_books.py` 가 모두 통과한다.
- [ ] `library.py` 의 모든 함수에 한국어 주석이 있다.
- [ ] `tests/` 폴더는 바뀌지 않았다. (`Compare-Object` 로 원본과 비교했을 때 차이가 없다)

## 6. 진행 방법
`AGENTS.md` 의 작업 순서를 따른다. 먼저 계획을 말하고, 내가 "진행"이라고 하면 구현한다.
끝나면 바꾼 파일과 통과한 테스트 개수를 보고한다.
