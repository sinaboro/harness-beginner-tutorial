# 검증 체크리스트 (명함 페이지)

> 이 파일이 "맞는지"를 판단하는 기준입니다. AI 는 이 파일을 고칠 수 없습니다.
> 완료라고 말하기 전에, 사람이 아래를 하나씩 직접 보고 체크합니다.
> 하나라도 빈칸이면 저장하지 않습니다.

## 1단계. 파일 확인 (1분)
- [ ] 폴더에 `index.html` 과 `style.css` 두 파일만 있다. (다른 파일이 생겼다면 AI 에게 되돌리게 한다)
- [ ] 두 파일을 메모장으로 열어도 글자가 깨져 보이지 않는다.

## 2단계. 브라우저로 열어 보기 (3분)
- [ ] `index.html` 을 더블클릭했을 때 브라우저에서 열린다.
- [ ] 페이지 맨 위에 이름이 가장 크게 보인다. (R1)
- [ ] 이름 아래에 한 줄 소개가 보인다. (R1)

## 3단계. 내용 확인 (3분)
- [ ] "취미" 제목 아래에 취미가 세 개 세로로 나열된다. (R2)
- [ ] "이메일 보내기" 링크를 누르면 이메일 작성 창이 열린다. (R3)
- [ ] 바탕은 연한 색, 이름은 진한 남색이다. (R5)

## 4단계. 좁은 화면 확인 (2분)
- [ ] 브라우저 창을 가장 좁게 줄여도 글이 가로로 잘리지 않는다. (R4)
- [ ] 가로 스크롤바가 생기지 않는다. (R4)
- [ ] 글과 취미 목록이 세로로 쌓여 보인다. (R4)

## 5단계. 코드 읽기 (5분)
- [ ] `index.html` 과 `style.css` 에 한국어 주석이 있다. (무엇을 꾸미는지 한 줄씩)
- [ ] 자바스크립트(`<script>`)가 없다.
- [ ] 외부 파일을 가져오는 줄(`http`, `https`)이 없다.

## 6단계. 저장 전 마지막 확인 (1분)
- [ ] 위의 모든 항목을 확인했다.
- [ ] 바꾼 파일과 확인 방법을 내가 말로 설명할 수 있다.

---

**체크를 다 했으면** 이 파일의 항목을 모두 체크한 상태로 저장합니다. 저장은 사람이 합니다. AI 는 저장하지 않습니다.
