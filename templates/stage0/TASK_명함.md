# 작업 지시서: 자기소개 명함 페이지 (0단계 6장)

## 1. 목표
`REQ_명함.md` 의 R1~R5 를 만족하는 명함 페이지를 HTML 파일 하나와 CSS 파일 하나로 만든다.

## 2. 요구사항
`REQUIREMENTS.md` (이 폴더에 복사해 둔 명함 요구사항)의 R1~R5.

## 3. 범위
- 새로 만드는 파일: `index.html`, `style.css` 두 개뿐이다.
- 고치면 안 되는 파일: `CHECKLIST.md`, `AGENTS.md`, `opencode.jsonc`

## 4. 하지 말 것
- 자바스크립트를 쓰지 않는다.
- 그림 파일이나 외부 글꼴, 외부 CSS 프레임워크(부트스트랩 등)를 가져오지 않는다.
- 요구사항에 없는 섹션(방명록, 입력 폼, 사진)을 덧붙이지 않는다.
- 파일 두 개 외에 다른 파일을 만들지 않는다.

## 5. 완료 조건
- [ ] `index.html` 과 `style.css` 두 파일이 있다.
- [ ] `CHECKLIST.md` 의 항목을 모두 확인했다. (사람이 확인한다)
- [ ] 두 파일 안에 한국어 주석이 있다. (무엇을 꾸미는지 한 줄씩)

## 6. 진행 방법
`AGENTS.md` 의 작업 순서를 따른다. 먼저 계획을 말하고, 내가 "진행"이라고 하면 만든다.
끝나면 무엇을 만들었고, `CHECKLIST.md` 의 어느 항목을 확인했는지 보고한다.
