# 작업 지시서: 할 일 목록 만들기 (6교시)

## 1. 목표
할 일을 추가하고, 완료 표시하고, 지우고, 파일에 저장할 수 있는 `todo.py` 를 만든다.

## 2. 요구사항
`REQUIREMENTS.md` 의 R1~R5 를 구현한다.

## 3. 범위
- 새로 만드는 파일: `todo.py`
- 고쳐도 되는 파일: `todo.py` 하나뿐이다.
- 고치면 안 되는 파일: `tests/` 폴더 전체, `verify.py`, `AGENTS.md`, `opencode.jsonc`

## 4. 하지 말 것
- 웹 화면, 데이터베이스, 외부 패키지(설치가 필요한 것)를 쓰지 않는다. 파이썬 기본 기능만 쓴다.
- 요구사항에 없는 기능(검색, 정렬, 마감일)을 덧붙이지 않는다.
- 테스트 파일의 기대값을 바꾸거나 테스트를 건너뛰게 만들지 않는다.

## 5. 완료 조건
- [ ] `python verify.py` 가 "검증 통과"로 끝난다.
- [ ] `tests/test_todo.py` 의 테스트가 모두 통과한다. (테스트 개수는 줄지 않았다)
- [ ] `todo.py` 의 모든 함수에 한국어 주석이 있다.
- [ ] `git diff tests/` 에 아무 변화가 없다.

## 6. 진행 방법
`AGENTS.md` 의 작업 절차를 따른다. 먼저 계획을 말하고, 내가 "진행"이라고 하면 구현한다.
끝나면 `AGENTS.md` 의 보고 형식으로 보고한다.
