# 요구사항: 할 일 목록 (6교시 미니 프로젝트)

## 한 문장 요약
할 일을 적고, 목록으로 보고, 끝낸 일을 표시하고, 지울 수 있는 명령줄 프로그램. 목록은 파일에 저장되어 프로그램을 껐다 켜도 남는다.

## 할 일 한 건의 모양
| 항목 | 설명 |
|---|---|
| `id` | 1, 2, 3 … 순서대로 붙는 번호. 지워도 다시 쓰지 않는다. |
| `title` | 할 일의 내용. 공백만 있으면 안 된다. |
| `done` | 끝났으면 `True`, 아직이면 `False`. 처음에는 `False`. |

## 기능 요구사항

### R1. 할 일 추가
- `add_task(tasks, title)` 을 부르면 새 할 일을 목록 끝에 넣고, 그 할 일을 돌려준다.
- 제목이 공백뿐이면 `ValueError` 를 일으킨다.

### R2. 완료 표시
- `complete_task(tasks, task_id)` 을 부르면 그 번호의 할 일을 `done = True` 로 바꾼다.
- 그 번호가 없으면 `ValueError` 를 일으킨다.

### R3. 삭제
- `delete_task(tasks, task_id)` 을 부르면 그 번호의 할 일을 목록에서 뺀다.
- 그 번호가 없으면 `ValueError` 를 일으킨다.

### R4. 파일 저장과 읽기
- `save_tasks(tasks, path)` 은 목록을 JSON 파일로 저장한다.
- `load_tasks(path)` 은 JSON 파일을 읽어 목록을 돌려준다.
- 파일이 아직 없으면 빈 목록 `[]` 을 돌려준다. 오류를 내지 않는다.

### R5. 명령줄에서 쓰기 (선택 사항)
- `python todo.py` 뒤에 `add`, `list`, `done`, `delete` 를 붙여 쓸 수 있다.
- 목록 보기는 번호, 완료 여부(`[x]` 또는 `[ ]`), 제목을 한 줄씩 보여 준다.

## 만들지 않는 것
- 마감일, 우선순위, 검색, 정렬
- 웹 화면, 데이터베이스, 여러 사람이 함께 쓰는 기능
