# 하네스 엔지니어링 입문 — 단계별 교안

**AI 에이전트에게 개발을 맡기되, 규칙·권한·검증으로 통제하고, 통과한 것만 저장하는 법을 단계별로 배웁니다.**

코드를 먼저 배운 뒤에 AI 를 쓰는 과정이 아닙니다. AI 에게 맡기면서 코드와 개발 원리를 함께 이해하는 과정입니다. 그래서 각 단계는 "하네스의 한 요소"를 하나씩 익히도록 설계했습니다.

| | |
|---|---|
| 대상 | 프로그래밍을 처음 배우는 사람 (코딩 경험이 없어도 됩니다) |
| 준비물 | Windows PC, Git, OpenCode, OpenRouter 계정 (1단계부터 Python 추가) |
| 필요 없는 것 | Docker, 데이터베이스, 웹 서버 (0·1단계 기준) |
| 에이전트 | OpenCode (OpenRouter 모델 사용) |

---

## 단계 안내

| 단계 | 대상 | 내용 | 상태 |
|---|---|---|---|
| **0단계** | 코드를 전혀 모르는 사람 | 프로그래밍 언어 없이, HTML·CSS 명함 페이지 한 장을 AI 에게 맡기고 하네스의 원리를 익힌다 | **이 저장소에 있음** (`docs/stage0/`) |
| **1단계** | 생초보 | Python 계산기와 할 일 목록 프로그램으로, 테스트와 저장 장치까지 익힌다 | **이 저장소에 있음** (`docs/stage1/`) |
| **2단계** | 초급 | 도서 대출 목록 프로그램으로, 저장, 상태 규칙, 요구사항 변경, 되돌리기를 익힌다 | **이 저장소에 있음** (`docs/stage2/`) |
| 3단계 | 실무형 | 3일 과정. FastAPI, PostgreSQL, Docker 까지 연결하는 전체 실습 | 별도 저장소 [harness-crud-lab](https://github.com/sinaboro/harness-crud-lab) |

## 1단계 교시표

| 교시 | 주제 | 배우는 것 | 결과물 |
|---|---|---|---|
| 0장 | 준비하기 | Python, Git, OpenCode, OpenRouter 연결 | 설치 확인 체크리스트 |
| 1장 | 하네스란 무엇인가 | 같은 부탁을 조건 없이 한 것과 조건을 붙인 것의 차이 | 비교 기록 |
| 2장 | 요구사항 쓰기 | "이렇게 하면 → 이런 결과"로 흐리지 않게 쓰기 | 계산기 요구사항 |
| 3장 | 작업 지시서 쓰기 | 목표·범위·하지 말 것·완료 조건 여섯 칸 | 지시서와 계획 검토 |
| 4장 | 규칙과 권한 세우기 | `AGENTS.md`(부탁)와 `opencode.jsonc`(잠금장치) | 규칙 문서, 권한 확인 |
| 5장 | 검증하고 저장하기 | 빨강→초록, 검증을 통과해야 커밋되는 훅 | 통과한 커밋 |
| 6장 | 미니 프로젝트 | 할 일 목록을 AI 에게 맡기고 통제하기 | 할 일 목록 프로그램, 과정 기록 |

각 장은 **학습 목표 → 개념 → 따라 하기 → 확인하기 → 자주 만나는 오류 → 확인 문제** 순서입니다.

## 시작하기

0단계(`docs/stage0/`), 1단계(`docs/stage1/`), 2단계(`docs/stage2/`) 순서로 따라 합니다.

**[PS]** 저장소를 내려받습니다.

```powershell
git clone https://github.com/sinaboro/harness-beginner-tutorial C:\harness-beginner-tutorial
```

교안은 PDF 로도 볼 수 있습니다. `docs/하네스_입문_0단계_교안.pdf`, `docs/하네스_입문_1단계_교안.pdf`, `docs/하네스_입문_2단계_교안.pdf` 를 여세요.

0단계부터 순서대로 합니다. 0단계는 Python 이 필요 없고, 1단계부터 Python 을 씁니다.

## 원칙 세 가지

1. **AI 가 쓰고, 사람이 판단합니다.** 코드는 AI 가 쓰더라도, 계획을 승인하고 결과를 읽고 저장하는 판단은 사람이 합니다.
2. **기준은 AI 가 고치지 않습니다.** 테스트와 검증 스크립트, 규칙 문서는 권한 설정으로 AI 가 고치지 못하게 막습니다.
3. **통과한 것만 저장합니다.** 검증이 실패하면 커밋 자체가 취소됩니다.

## 강사 안내

- 교안의 실행 결과는 0장~6장의 명령을 실제 Windows PowerShell 에서 확인한 것을 기준으로 합니다. OpenCode 의 AI 답변은 실행할 때마다 다르므로, 교안에는 답변 내용 대신 **확인 방법**을 적었습니다.
- 6장에는 정답 코드를 싣지 않았습니다. 학생이 테스트와 지시서를 읽고 AI 와 대화하며 맞춰 가도록 한 것입니다.
- 3단계(3일 과정)는 별도 저장소 [harness-crud-lab](https://github.com/sinaboro/harness-crud-lab) 에 있습니다. 2단계 7장을 마치면 그 저장소로 이어 갑니다.
